## Lessons

- **Unit tests that stub WooCommerce classes hide boot fatals** (#49): a class extending `WC_Email` loaded before WC → fatal on a
  real site, green in phpunit. Gotcha `a-stubbed-wc-class-hides-a-boot-fatal`.
- **A semantic conflict between two parallel branches surfaces as a missing Brain Monkey stub** after a clean textual merge —
  run the full suite on the merge commit, never trust the two branch greens.
- **Never `&` a watchdog** — happened twice again; only the background tool. Already a memory rule (s178).
- A worker printed the rig's `.wp-env.override.json` into its own transcript (P20). Nothing reached a repo or report; noted to the
  operator.
