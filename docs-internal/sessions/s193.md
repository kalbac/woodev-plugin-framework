  run the full suite on the merge commit, never trust the two branch greens.

### Lessons (night)

- **A worker that ends its turn without `worker_done` is invisible to the watchdog** — W6 sat finished for an hour. For remote
  writers, put «send worker_done yourself, do not end the turn without it» in the brief, and run a terminal-idle poller alongside.
- **The watchdog exits on `remote_runtime_unavailable` blips** — wrap it in a retry loop for remote handles.
- **Each remote Claude session costs ~300–400 MB with its MCP servers**; on the 14 GB Homelab keep ≤ 2–3 and release finished ones.
- The operator's review notes were in the Desktop copies, not in the WordPress drafts — ask where notes live before dispatching.
