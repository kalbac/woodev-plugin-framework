  (57× 64×36×40, 3× 36×64×40, 2× 64×21×40 — MSK414, MSK415), SPb 19/19, all `weight_max` 30 kg.
- **`/deliverypoints` filters by parcel `length/width/height`** (with rotation): 60×30×30 drops exactly the two 64×21×40 lockers;
  65×40×40 drops all. The plugin already passes the dims, so unfit lockers vanish; our cell check stays a safety net.
- **Calculator does not gate postamats:** 368 is quoted up to 50 kg physical/volumetric, same as 136; 2 places to a postamat are

## Operator decisions applied

- Milestones: framework wrapper (random exclamation + plugin fragment + static review paragraph), not a bypass.
- Tariffs: group by «Услуга»; keep Посылка, Экономичная посылка, Экспресс, Магистральный экспресс, E-com Express, E-com Standard;
  no custom-code field (a filter instead); separate postamat method.
- `ALL` is legitimate when the type is unknown; a known tariff sends PVZ/POSTAMAT.
- Postamat: no packing option, one virtual parcel, no 15 kg cap. Services per method as agreed.
- Hooks: declare only the 39 that shop code used.
- Competitors: all notices visible at the top (WC Store Alerts, as v1); «плагин стороннего разработчика», never «чужой»;
  conflict ends «Во избежание конфликтов отключите плагин …»; recommendations sell (more functions, stability, updates, support)
  in 9 different texts rotated as shared templates.
- Grouped `use` imports everywhere (PHP 7.0+); minimum PHP will follow WooCommerce to 8.3 (#1228).

## How the work went

- **Three bugs passed green tests because the tests mocked the very seam that was wrong:** REST validation (handler called directly),
  `is_plugin_active` (mocked), WC note actions (stub stored `is_primary`). All three are gotchas now.
- **A stale `woodev/` copy inside the plugin** made the admin map fail on the rig until `scripts/sync-framework.sh` — the rule existed.
- **Worktrees made with `git worktree add` are invisible in Orca's sidebar and get no `vendor/`** — the operator asked why he saw no
  process. Make worker worktrees through Orca.
- A worker's Serena edits leaked into the PRIMARY plugin checkout (copies of its branch changes) — discarded after comparison.
- A coordinator command chain with `;` ran a `sed` in the wrong checkout after a failed `cd` — reverted; use `&&`.
- The operator's message was cut by a notice once («Пи… ши»); the rest arrived separately — waited for it before writing copy.
