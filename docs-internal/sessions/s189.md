## Lessons

- **Orca `--base-branch v2` took the stale LOCAL ref again** (gotcha `orca-worktree-create-base-branch-takes-the-local-ref`):
  the CDEK release worker branched without the just-merged #124; caught by the unit count (1576 instead of 1586), rebased by the
  coordinator, ZIP rebuilt. Fast-forward local plugin refs after every `gh pr merge`.
- Two PRs that each add a gotcha both bump the GOTCHAS.md header from N to N+1 — the second to merge fails `lint:docs` on CI.
- The watchdog exits on every non-heartbeat delivery, including stale ones it already acked — read the subject before acting.
- A coordinator merge with a check still `pending` (#1379, Secret scan) — wait for every job, even when mergeStateStatus is CLEAN.
