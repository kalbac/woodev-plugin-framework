## Facts learned

- **The «Локация» section exists only when some plugin returns `true` from `needs_location_provider()`.** The layer opens
  fleet-wide, so a three-carrier rig hides a plugin that forgot it; acceptance must include «the plugin alone». Framework
  guard → #1420 (PR #1421).
- Opting in is not enough: the cascade mounts only for fields declared with `->source_location()` (region, settlement,
  address), as CDEK/Yandex do.
- The theme's product gallery = featured image (hero, full size — `woodev-banner` is unregistered) + `_product_gallery_images`
  (comma-separated ids, meta order = display order), shown in a 16:9 `object-cover` box; thumbs are a hard 150×150 crop.
  Buyer screenshots must be 16:9 (1280×720). EDD «banners» are the update-popup images, not the product page.
- `update-card` cannot set title, excerpt, product notes or `_faq_content`; those go through homelab-ai WP-CLI.
- The baked local-ci image lacked `php-sqlite3`; 51 SQLite-backed migration tests error only under local-ci (`php:7.4-cli`
  has it built in). Russian Post `299bc81`. CI phpcs runs `--warning-severity=1` — four capability warnings had been red
  in local-ci since the migration screen landed; fixed in `213a00f`.
- Draft GitHub releases in a private repo are a clean Mac→Homelab file channel (`gh release download` on Homelab; delete
  after use) — far better than base64 chunks through `orca terminal send`.

## Lessons (process)

- The release checklist missed `plugin_version` in the loader array of the main file; `build-release-zip.sh` refused the
  mismatch. Bump all five spots: header, constant, loader `plugin_version`, `Plugin::VERSION`, the boot test.
- A worker heartbeat-ack cadence plus a background `check --wait` per dispatch kept every report seen overnight.
