## Operator decisions (09–10.11.2026)

- **React wherever applicable, PHP-driven** (AGENT-RULES Rule 9): products, orders, mappings, tools, diagnostics, settings.
  Screens embedded in WooCommerce's own UI (product edit tab, order metabox) stay classic. The spec's «classic admin, no React
  pages» line was the coordinator's own provisional choice, never asked.
- **Own top-level menu** «OZON Seller» (Ozon Seller icon from v1) through `wc_admin_register_page()` without `parent` (verified in
  WC `src/Admin/PageController.php::register_page()` → `add_menu_page()`); submenus Настройки / Товары / Заказы / Сопоставление /
  Инструменты / Диагностика; landing «Товары». Settings live there, never under Woodev → Настройки (only future shared
  marketplace settings may go to Woodev → Настройки → «Маркетплейсы»).
- **Base class:** `\Woodev\Framework\Marketplace\Marketplace_Plugin extends \Woodev\Framework\Woocommerce_Plugin`, like
  `Shipping_Plugin` / `Woodev_Payment_Gateway_Plugin`; it owns menu/page/settings registration. Namespace
  `Woodev\Framework\Marketplace\*`. Spec §7.1 «layer inside the plugin until WB» (option B) is replaced by «framework now».
- **Delivery is never touched.** «Заказы доставки» stays as it is; the products table is a new framework component that only
  takes it as a reference (filters, sorting, bulk actions, row lock, per-row progress). The design's F8 «shipping adoption» was a
  misreading and is removed for good.
- **Analytics:** reserved slot only; designed after the core works (as delivery analytics was).
- Variable products: parent row with expandable variations, each with its own state and progress.
- Multi-account is NOT dropped (the rig simply had one account).
- Mid-port UI PRs merge on critic + CI; visual nits go to one pre-release card (plugin #58). He wants to try screens by hand —
  offer a clickable rig, not screenshots. His polish rules: buttons never wrap (shorter text or icon buttons), raw URLs wrapped
  in link text.
- **Limits:** Claude waves ≤ 3 workers; Codex ($20 vs Claude $100, drains ~5× faster) is a critic only, used sparingly.
