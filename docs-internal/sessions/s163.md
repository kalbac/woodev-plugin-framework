## Field guard (main regression found by acceptance)

The notice printed before headers on every page with `WP_DEBUG` display on, so `wp-login.php` set no cookie: framework e2e 10/11
red, CDEK acceptance blocked. Fix: the guard tracks each claim's signature (`location:<level>` vs direct) — same level silent;
direct-vs-location, direct-vs-direct and different levels still reported. After syncing the fix into the primary checkout and the
CDEK plugin's copy: no notice on `wp-login.php`, e2e back to 9 pass / 1 known precondition fail.
