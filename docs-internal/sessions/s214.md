## Operator decisions (full text in the agenda)

Plugin: (1) manual number for any carrier + numbers pulled from our carriers; buyer display of carrier numbers moves to the
**framework** (#1575); (2) no own tracking table in framework delivery mails, the Russian Post mail or admin mails; (3) own mail auto-sent
for each new manual number (setting, default on), button stays for resend; (4) **no carrier statuses in the plugin** — «этот плагин не про
это»; (5) carrier list re-checked, dead ones dropped, own carriers in settings, filter kept; (6) licence off → existing numbers always
visible, adding/sending blocked with a clear message; (7) every v1 contract kept byte-exact; (8) settings on `woodev-settings`, email texts
stay in WC → Email; (9) **2.0.0, 3 000 ₽**; (10) no docs beyond the product card (one page at most), no migration screen, no wizard, no blog,
no Telegram, no separate board, private repo `kalbac/woocommerce-order-tracking-number` (created, empty); (11) framework #1575 and
the plugin ship in one wave; (12) «дропшиппинг» = manual number with own carrier, a usage example on the card; (13) auto-send on for
upgrading shops too, with an «отправлено автоматически» note on the order.

#1575 (card comments): number-link + one «Текущий статус» line, no history table; one line per shipment «Отправление N из M» (Ozon); each
number its own link in HTML mails; render on `woocommerce_order_details_after_order_table`, nothing when there is no number; Ozon public
tracking URL not confirmed (number without link until a browser check).
