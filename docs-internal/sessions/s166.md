## How the work went

- **Two watchdogs on one Run both consume the same inbox delivery.** Run ONE watchdog with all live handles; restart it after each delivery (TaskStop the old one).
- **A Claude worker cannot push JS changes from a worktree** (pre-push rebuilds bundles that never match CI). Recipe used, per the gotcha:
  1. the worker pushes with `--no-verify` on the coordinator's word;
  2. the coordinator rebuilds in the primary checkout, detached at the branch;
  3. the coordinator commits the bundles and pushes `HEAD:<branch>`.
- **`orca worktree create --base-branch v2` used the stale LOCAL `v2`** (gotcha `orca-worktree-create-base-branch-takes-the-local-ref`) → `reset --hard origin/v2` before dispatch.
