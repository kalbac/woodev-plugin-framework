## Сделано

- **#1048 → PR #1058:** `save_step()` мастера ловит `\Throwable` из `on_save` (раньше только `\Exception` — `TypeError`
  вылетал из REST), лог через `redact_secret_log_text()`, наружу общий HTTP 500 `woodev_setup_step_failed`.
  **Смена поведения:** текст исключения из `on_save` раньше показывался админу (400) — теперь нет. Безопасный канал для
  сообщений автора — предложение 2 аудита, отложено до плагина (решение s147). Codex luna: ACCEPT WITH NITS.
- **#956 → PR #1059:** уведомление мерчанту, когда DaData отказывает. Бриф ошибался: **у DaData нет 402**, кончившиеся
  деньги — 403 наравне с неверным ключом (готча `dadata-has-no-402-an-exhausted-balance-is-a-403`). Опция
  `woodev_location_dadata_access_denied` ставится первым 403 подсказок, снимается следующим 2xx; уведомление без кнопки
  закрытия, только пока DaData активный провайдер. Codex luna: ACCEPT WITH NITS. Идея проверки баланса → **#1060**.
- **#958 → PR #1063:** кэш успешных тарифов. Раунд 1 — **REJECT** от Codex **gpt-6.1-sol high** (ключ без ПВЗ/оплаты/улицы/
  глобальных настроек при включённом по умолчанию кэше; упаковщик читает `is_virtual` и единицы). Решение координатора:
  **opt-in** (`Shipping_Method::FEATURE_RATE_CACHE = 'rate-cache'`) + публичный seam `get_rate_cache_context()`; в ключ
  по умолчанию добавлены улица, способ оплаты, ПВЗ этого метода (новый `Pickup_Handler::get_selected_point_for_method()`),
  `is_virtual`, единицы, режим упаковки. Раунд 2 — Codex luna ACCEPT WITH NITS (рекурсивный массив → **#1062**).
  Воркер переписал публичный `docs/shipping-method.md` — откачено (публичные доки заморожены до v2).
- **#1047 → PR #1061:** степпер мастера — `aria-current="step"`, скрытый текст статуса шага, фокус на заголовок шага после
  перехода; провал «completed» — экран «Готово» + плашка «Повторить»; провал «skipped» — первый клик блокируется, второй
  выпускает. Codex luna: ACCEPT WITH NITS, два P2 (двойной клик, сброс флага при hash-навигации) починены, правку проверил
  координатор. Бандлы и 5 msgid собраны в основном чекауте. **Принят оператором на риге.**
- **#955 → PR #1064 (не смержен):** габариты/вес по умолчанию. Обсуждён с оператором: **общие для всех перевозчиков**
  (габариты описывают товар; покупатель сравнивает службы на одной посылке; одно место при 4+ перевозчиках). Довод воркера
  «упаковщик строит один набор на всех» — **ложный** (каждый метод упаковывает сам, `class-shipping-method.php:837`).
  Решения оператора: значения по умолчанию **100 г / 10×10×10 см** (как в v1) в единицах магазина, поля **обязательные**,
  описание секции с рекомендацией заполнять карточки товаров, `min`/`step` в браузере **только у этих четырёх полей** (не
  для всех числовых полей фреймворка — его слово). React-контрол числа терял `min`/`step` — сделан opt-in `native_bounds`.
  Перенос v1 `default_*` — дело lifecycle нового плагина, не фреймворка (решение координатора, записано на #786).

## Процесс

- Воркер #958 встал на «API Error: Connection lost mid-response», `worker-list` показывал его `live` — координатор сообщил
  оператору «все живы», заметил оператор. Готча уже была (s146); теперь у каждой волны фоновый сторож, читающий хвосты
  терминалов (локальная память `run-a-terminal-watchdog-for-every-worker-wave`).
- Модель критика переключалась правкой `~/.codex/config.toml` на время запуска (sol high для нового дизайна #958) и
  возвращалась на luna — запуск без `--model` прошёл штатно (Orca 1.4.218).
- Критики стабильно запускались через `worker-start --agent codex --worktree current` и присылали `worker_done` с файлом.
- Лимиты в конце: Claude ~51 % сессия / 36 % неделя; Codex ~40 % / ~78 % неделя (сброс вт).
