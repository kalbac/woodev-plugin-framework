- **`supported_features.blocks` = true по умолчанию для плагинов ДОСТАВКИ** (не глобально — у платёжной части нет блочной
  интеграции). Порядок: сначала вариант 2 (переопределение в `Shipping_Plugin`) замером, не сработает — вариант 1 (тип в
  loader definition) → **#1121** («Следом», следующая сессия).
