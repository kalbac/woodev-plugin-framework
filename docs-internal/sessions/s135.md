## Ключевые решения (мои, с обоснованием)

1. **`GOTCHAS.md` → карта тем + `gotcha-index/{topic}.md`.** Сумма стояла на 175.3 из 176 КБ,
   `GOTCHAS.md` на 95.4 из 96. `DOCS-SCHEMA` на этот случай уже предписывал: «третий раз не поднимать,
   делить по тегам» (#554). Потолок `GOTCHAS.md` 96 → 16 КБ; сумма оператора (176) не тронута.
2. **Формат шапки готчи ослаблен до того, что делает корпус.** `# Gotcha: [topic/slug]` + `> Tags: … |
   Session:` соблюдали ~40 из 321; то же решение, что для вики в s119 — правило, которое корпус
   игнорирует, вводит в заблуждение. Обязательны H1, `## Related` с настоящей ссылкой, строка индекса.
3. **Гейт запрещает `[[wikilink]]`** — две мёртвые такие ссылки прошли гейт незамеченными; ещё десять
   живых сконвертированы. Плюс (по находке критика): форма тега, одна строка, одна запись на готчу,
   счётчик в карте. Суффикс `(sN)` и совпадение пространства имён — вручную: корпус их не держит (23 и 5
   исключений), замерено.
4. **Зеркальные чек-листы начала/конца сессии удалены** из `AGENT-RULES.md` и `DOCS-INDEX.md` — оба
   разошлись с `AGENTS.md`; копия дрейфует всегда, поэтому ссылка вместо синхронизации.
5. **`QWEN.md` сведён к указателю** — ошибался в десятке мест (поле `version` вместо
   `framework_version`, правило `@since`, 3 фикстуры вместо 8, порты 8888, …).
6. **Две машины: git + gitignored `.machine-transfer/`**, зависимости переустанавливаются, личные
   настройки не копируются. Префикс контейнеров wp-env — хеш абсолютного пути, поэтому в доках больше
   не вставляется: `scripts/machine/rig-container.sh`.
7. **14 CRLF-блобов нормализованы в LF** — из-за них каждый свежий ворктри (и клон на Маке) рождался
   грязным; дифф пуст при `--ignore-cr-at-eol`.
