  = «Готовится к отправке»; `acceptance_in_progress` = «Передано в доставку»; `forming_failed`/`not_accepted_to_delivery` = «Возникла проблема с отправлением».

- **Framework `VERSION` was NOT bumped on `main`** (still 2.0.24); the plugins require 2.0.25, so the rig runs on a local, unpushed branch with a
  version bump. Ozon/Yandex `ci.yml` pin `WOODEV_FRAMEWORK_REF = e315bbc5` (before #1585); both bump to the 2.0.25 tag at release.
- **Deferred pre-existing defect** (critic PR #6 r2): `Items_Store::is_from_provider()` (`includes/class-items-store.php:326-331`) compares unresolved encoded names through `wc_clean`, so `wc_otn_delete_tracking_number()` with the slug of a REMOVED merchant carrier can delete another carrier's item with the same number. Near-zero probability; filed as `woocommerce-order-tracking-number#7` (bug, board №6, «Бэклог» / «Потом»); fix = keep the encoded identity, never match an empty value.
