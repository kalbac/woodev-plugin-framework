## Ozon 2.0.1 — hotfix (operator report at ~03:50 MSK)

Report: on `ozon.wootest.ru` and `wootest.ru` (one multisite, fresh installs of 2.0.0) the pickup method («Пункт выдачи Ozon») was
missing while courier was always present; later, the pickup map did not load without a merchant key.

| Root cause (measured on the demo sites) | Detail |
|---|---|
| Slow first load | After the keys are saved the plugin downloads ~93 000 points. Each Action Scheduler run did 1 list page or 10 info batches (~7 s of work plus lag); the first full catalogue took ~1 h (wootest.ru: started 03:19, complete 04:20 MSK). Until a point has details it is not served, so pickup was silently hidden |
| Undefined constant | `WOODEV_OZON_DELIVERY_MAP_FALLBACK_KEY` was read by `class-ozon-pickup-checkout.php` but never defined (Yandex and Russian Post define theirs in the main file) |

**Operator decision:** ship a bundled static catalogue with the plugin; the settings say that the bundled list is being updated.
**Coordinator refinement:** the snapshot cannot carry the merchant's own `shipment_method_ids`, so the order is: seed details from
the bundled file → a fast list pass fills the merchant's method ids → the info pass refreshes details in the background.

`kalbac/woodev-ozon-delivery#76` (worker Sonnet 5.5; critic Codex luna, two rounds):

- time budget 20 s per run; bundled `assets/data/ozon-delivery-points.json.gz` (93 441 points, 3.5 MB, generated 02.11.2026 by
  `tools/build-catalogue-snapshot.php`, which is not shipped); chunked, resumable seed; a `catalogue_loading` refusal (debug-only);
  a first-load notice on the settings page, the wizard's last screen and the tools card;
- map fallback key `8bc059fe-…` (the Yandex Delivery plugin's key, verified from `ozon.wootest.ru`);
- fix round: the seed `INSERT` result is now checked (critic); `&nbsp;` printed literally in the tools card (found live); the list page
  is upserted in 2 multi-row queries instead of 1000 (found live: ~7 s/page);
- 647 tests, phpcs, phpstan, CI PHP 7.4 / 8.3 green.

**Measured live on `ozon.wootest.ru` with the final build:** «Очистить» + «Обновить сейчас» at 01:38:03 UTC → all 93 441 points served
at 01:41:26 UTC (**~3.5 min instead of ~1 h**). The notice read «Используется встроенный список пунктов выдачи от 02.11.2026. Идёт
обновление из Ozon (обработано 3 773 из 93 441), ничего делать не нужно.» Checkout, Saint Petersburg: «Пункт выдачи Ozon: 208 ₽»; the
