## How the work went

- Plugin release PRs need no GitHub CI (private repos blocked until 01.11): merge evidence = coordinator local-ci + Codex.
- `npx run-local-ci` in a fresh Orca terminal stops on «Ok to proceed? (y)» — use `npx -y`.
- A coordinator terminal consumes ONE Run: a new `run-create` rebinds it, and `check` on an older Run is `consumer_fenced`;
  two waiters on the same Run race and both read an error. One waiter per Run.
- A worker terminal Orca no longer recognises (`agent_unconfigured`) still takes a prompt typed into it; report via a
  `status` message to the bound Run.
- Codex readiness stops on its update dialog: `3` («Skip until next version») clears it until the next version.
- Stacked PRs + squash merge → the second PR conflicts in `.min.js` and bundles; resolve: files only the first PR touched
  from `main`, `npm run build:min` in the worktree, `npm run build` in the PRIMARY checkout with the porcelain
  before/after discipline, push `--no-verify` (the worktree pre-push hook always refuses a `src/` diff).
