## Decisions (operator)

Recorded verbatim on #1179. Highlights: `geo_id` with a strict rule, never the smallest id; 5Post as a per-method network setting
(framework «network» field only if Pochta needs it); identical parameters to calculator and offer; one adapter for DaData and
CDEK records, no own provider; framework map only, widget and the Metrika counter removed; express after v2;
`info.referral_source = 'woodev'` is mandatory (partner commission) with a contract test; `station_id` as one text field per method,
v1 warehouse table dropped; interval display modes none/list/range/latest; never hide a method silently (log, token check,
admin-only hint); CDEK coexistence acceptance in five scenarios; migration as CDEK v2, version **2.0.0** with ordinary semver;
export through offers with a shop-configurable price-growth threshold (RUB or %, default 10 %); a NEW repository for the plugin.
