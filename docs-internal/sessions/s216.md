## Lessons (how the work went)

- **My EDD brief said «do NOT change the featured image» and put the shots into «the gallery» without naming the meta** — the worker inserted them
  into the body. A product-card brief names: cover 1000×750 featured image, `_product_icon` (512 square), `_product_gallery_images` for shots.
  The convention table is in the Homelab report `2026-11-05-tracking-card-fix.md`; memory `a-plugin-release-ships-a-full-materials-package` updated.
- **«Текст карточки — как сейчас» still means «true»:** the v1 card text carried v1 behaviour (manual mail, Boxberry, export auto-add). A card
  kept «as is» is checked claim by claim against the new code before publishing.
- Mac → Homelab file transfer: a temporary release asset on the plugin's own release (deleted after download) — an http.server on the
  Tailscale IP is denied by the classifier.
- `orca worker-start --worktree new-top-level --base-branch origin/main` → `repo_not_found`; create the worktree with `orca worktree create
  --no-parent`, then `--worktree "id:<repo>::<path>"`.
