## Lessons

- Catalogue conflicts between parallel UI PRs: union the `.po`/`.pot` blocks, then `msgfmt -c` — a union merge drops `msgstr`
  lines at block borders; two entries on `main` («Удаляется…», «Карточек») had none already. JS msgid references must point at
  `assets/build/<dir>/index.js`, never `src/…`, or `build:js-i18n` fails and deletes a bundle JSON.
- A stale Composer classmap fails `ClassMapCompletenessTest` after merging new classes — `composer dump-autoload`.
- Workers cannot see their UI on the rig (it loads the Ozon copy of the framework); a CSS claim needs a measured fixture, not reasoning.
