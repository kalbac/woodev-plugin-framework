### Решения оператора (06–07.10.2026)

- **Первый перевозчик — СДЭК**, тот же репозиторий, код с нуля в ветке `v2`; клиентам — только при полном паритете (этапы 1–4). На #786.
- **Ключ разработчика `WC_CDEK_SHIPPING_DEVELOPER_KEY`** — константа в главном файле плагина, уходит полем `developer_key` при
  создании заказа (`includes/orders/class-cdek-order-request.php`). Закоммичен (`3ca6abe` на `v2`).
- **Резервный ключ Яндекс Карт** — тот, что в старом плагине СДЭК (`plugins-reference`), константа `WC_CDEK_YANDEX_MAPS_FALLBACK_KEY`.
- **Курьер — `edostavka_courier`, ПВЗ — `edostavka_pickup`.** Старые заказы с `edostavka` распознаются везде; перенос из v1 меняет id
  экземпляров зон (номер и настройки сохраняются), правит ссылки на id (COD `enable_for_methods`).
- **Письма по статусам доставки — ОДИН набор на весь сайт** (регистрирует фреймворк), названия «Доставка: …», тег `{carrier_name}`.
- **Вкладка перевозчика называется коротким именем** («СДЭК»), не именем плагина.
- **Ключ Яндекс Карт — общий**, «Доставка» → «Карта». **«Коробки» → «Упаковка»**, таблица на React.
- **Вкладка СДЭК — три секции:** «Подключение», «Расчёт доставки», «Отправка» (+ «Выгрузка» фреймворка — сливать ли, решит на приёмке).
- **Тестовый режим — встроенные опубликованные тестовые ключи СДЭК**, поля ключей блокируются; город отправителя — выпадающий список с поиском.
- **Правила подписей и подсказок (AGENT-RULES Rule 10) обязаны быть в КАЖДОМ брифе с интерфейсом** — первый проход плагина их не знал.

### Решения координатора (обратимые)

- «Выгрузка» фреймворка оставлена отдельной секцией (оператор говорил «3–4 секции»).
- **Версию плагина не поднимаем ради рига** (находка критика F2: перенос курьера не перезапустится там, где v2 уже стоит) — на риге
  перенос запускается руками перед приёмкой.
- Во фреймворк добавлены два общих элемента вместо самодельного UI в плагине: **`search-select`** (выпадающий список с поиском через
  REST фреймворка) и **`disabled_if`** (блокировка поля по условию, как `show_if`). Контракт зафиксирован координатором для обоих воркеров.
