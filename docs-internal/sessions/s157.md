## Решения координатора (обратимые, записаны)

- **ПВЗ — отдельный метод `edostavka_pickup`**, курьер остаётся `edostavka`: фреймворк различает ПВЗ по id метода
  (`Checkout_Config::pickup_method_ids()`), один id не может быть и тем и другим. Перенос экземпляров — в миграции.
  **Временно, ждёт подтверждения оператора** (развилка на #786).
- Офис/постамат внутри `edostavka_pickup` — фильтр `woodev_shipping_pickup_point_selectable`.
- Цена — `total_sum` расчёта по тарифу (что магазин платит СДЭК), в валюте магазина.
- `/location/coordinates` не включён в цепочку: на боевом узнаёт города, но не сёла и в 3 случаях дал объемлющий город.
