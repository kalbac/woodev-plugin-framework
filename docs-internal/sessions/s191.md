## Facts learned

- **Russian Post APIs (all measured on the test account):** tracking moved to REST by token
  (`postapi.pochta.ru/tracking/api/external/v1/info`, `Authorization: ApiKey`); Ф7 needs a batch for every domestic product
  except EMS; international order create works (customs declaration forbidden for KZ/AM/KG, required elsewhere); domestic
  products reject a goods list; mass limits per product; ЕКОМ 53030/53070 answer HTTP 200 + error 1204. Details: the research
  folder and the spec amendment.
- **v1 international bug:** v1's country table sends Slovakia/Croatia/Serbia/Oman parcels with another country's code. Not fixed
  in v1 (v2 is the answer); the operator may want a post.
- **woodev.ru:** EDD SL decides a download by the licences of the link's ONE order; the account card links the newest order.
- **GitHub:** the private-repo Actions pool is exhausted until 01.11 (spending limit) — hosted CI does not start for any plugin;
  local-ci + php:7.4 docker + a Codex critic is the merge evidence. A burst of `gh project item-edit` calls hit the secondary
  GraphQL limit for ~50 min.
- **Launchpad PPA outage** (503, ~50 kB/s) silently broke setup-php's 7.4 install under local-ci; fixed by baking PHP into the
  image. CDEK and Yandex need the same fix (edostavka#128, yandex#130).

## Lessons (process)

- **Read exit codes, never a `tail`.** My phpcs check piped to `tail` hid 21 errors I had introduced; `v2` went red until fixed.
- **Never start a watchdog with `&`.** Twice this session a stray `&` left an orphan watcher; one process per wave, in the
  background tool only.
- **Workers must not run local-ci in parallel** — two runs on one Docker host made a real 7.4 failure look like a flake.
- **The coordinator's own diff review catches what a critic round misses** (P10's 24 h hold on a transient outage).
- **Serena's language server failed to start for one plugin worktree** in the coordinator session; PHP edits went to workers.
