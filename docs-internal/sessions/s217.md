## Key decisions (operator, 05.11.2026) — full list in spec §0

- **Full release, «second life»** (not a lean one); the straight-line mode «was badly missing»; foreign geo-service payment from RF is the
  main sales blocker — the operator explains payment routes at card/docs time.
- **DaData is ALWAYS the geocoder and suggestion source**; services only compute distance. Six services as **connectors** («Расчёт
  расстояния»: По прямой built in + ORS, 2GIS, Yandex, Mapbox, Google Routes); each method picks one; failure → straight line.
- **Warehouses table** on the settings page, one «Основной», method field 0/1/many states with «Ближайший к покупателю».
- **Rules redesigned** — simple contiguous distance grid (row-1 «от», others «свыше N»), v1 rules convert with identical prices or stay in an
  advanced engine. Products without weight use the framework default weight (`Default_Dimensions_Settings`) in the grid.
- «Требовать точный адрес» + approximate-price notice placement select; **classic AND block checkout** in the first release.
- **Price 4 000 ₽**; v2 to every active licence; demo site via Homelab AI.
