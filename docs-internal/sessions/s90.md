## The operator's rig pass is the story of this session

Programmatic verification (1380 jest tests, five Codex rounds, a driven browser pass of my own) said
the feature worked. It did. Then the operator looked at it and found four things, none of which any
of that could catch:

1. **The notice rendered ABOVE the settlement field**, so it read as belonging to the region field.
   Anchoring it immediately after the field is right in the DOM and wrong on screen for
   `ajax-select2`: select2 leaves the real `<select>` hidden in place and draws its own container as
   the next sibling. Fixed by appending to the field's own parent — after every node any renderer
   drew, without this module naming any of their markup.
2. **Nothing had ever styled `.woodev-location-notice`**, so it inherited the theme's `<p>` size and
   rendered at heading scale.
3. **No feedback for 2.4–4.5 seconds.** The measurement moved the design here: a `/select` round trip
   is 4527 ms for a region, 2391 ms for an ordinary settlement, 3493 ms for one needing the D7
   provider check. The verification is not what makes it slow — the round trip is, and the stale path
   is *faster* than picking a region. So the busy state is immediate and unconditional; a delay
   threshold would only mean the slow path shows nothing for its first fraction.
4. **The spinner sat 4px high** — `.woocommerce-input-wrapper` is `display: inline`, so its box is a
   line box sized by `line-height` (30px) while the control is 50px. Gotcha written.

## #337 overturned, on purpose and on the record

The address used to unlock on the settlement pick itself, off the optimistic record — #337's own test
said so in words: *"The /select round trip is still in flight — the customer must be able to type
now."* It now waits for the server's confirmation.

What overturned it was a measurement, not a preference: that round trip is 2.4–4.5 seconds, not the
instant #337 assumed, and the record it unlocked off can still be REFUSED — a D7 `cancelled` wipes
the settlement and re-locks the address underneath whatever was typed meanwhile, while the address's
own `/suggest` would carry a scope key the server never accepted. Twelve tests asserted the old
timing; only the one whose subject *was* the timing changed meaning.

Recorded in `isAddressLocked()`'s docblock, at #337's old call site, and as a comment on issue #337 —
three places, so it cannot be quietly restored by someone reading only the code.

**And a process failure worth keeping:** I asked for an explicit "we are reversing #337", got a
general "да, всё верно" aimed at the previous message, and treated it as the answer. The operator
caught it. Nothing had been pushed — the work sat in the working tree and then a stash — but the
correction is the point: an explicit question deserves an explicit answer, not a nearby one.

## The admin half was built wrong

D8's two merchant actions shipped as two separate fields-less connection sections. The spec called
the connection-test seam an *"implementation-time check"*; I ran that check, found the seam
technically fits, and converted a technical answer into an interface decision without ever showing
the operator what it would look like. All session I had held UI work for his judgement — and applied
that rule to the checkout while never applying it to the admin.

His shape: a **«Инструменты»** section, last on the «Доставка» tab, both buttons in it, built as a
registry any carrier plugin can register into. Spec: `specs/2026-08-25-shipping-tools-section.md`,
card #505.

He also corrected a factual claim of mine — WooCommerce's tools DO support a form before the button
(`selector`, `html-admin-page-status-tools.php:41-54`). His resulting idea is better than what I
built: with the provider chosen **explicitly** in the tool, the staged-vs-persisted guard that cost a
full critic round has no premise left, and everything that existed only to serve it unwinds with it —
including a breaking widening of the public `Woodev_Settings_Connection_Test` interface.

## Orchestration

Four Sonnet workers, three Codex critic passes across two cards. Codex earned its place: it found the
D8 **HIGH** where an unsaved provider switch let «Очистить» delete the persisted provider's list, and
the **MEDIUM** where the repair widened a credential boundary so every connection callback in the
framework began receiving the tab's other stored secrets.

Two of four `worker-start` launches hit `agent_prompt_stalled`. Enter recovers the work but never the
dispatch — the capability is revoked ~30s in, so `worker_done` arrives wrapped in a rejection and the
task must be closed by hand. Added to the existing gotcha.

**Memory: the Telegram plugin was leaking ~230 MB/hour per session.** Two 16-hour-old `bun server.ts`
instances held 7.35 GB of commit between them — more than Docker and the browser together. Disabled
at the operator's word; commit went 44.6 → 36.2 GB. The 2–3 agent ceiling was never really about
agents.
