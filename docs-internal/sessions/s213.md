## errors.woodev.ru (GlitchTip) triage — NEW, lives in n8n

- Daily 07:00 MSK plus one Webhook node (HMAC) on every plugin repo (the daily run ensures the hook exists). Repo = GlitchTip project name; skip list `woodev-rig`.
