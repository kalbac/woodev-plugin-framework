# s152 — 2026-10-05 — SP-11: #1096, #1100, #1090 (C-3) смержены; брейншторм и развёртывание GlitchTip (#1082)

**Итог:** смержены PR **#1103** (#1096, `ffd12461`), **#1104** (#1100, `a0abfad7`), **#1105** (#1090 C-3, `017fe108`). Открытых PR
нет. MacBook, оператор весь вечер; следующая сессия — овернайт без него.

## Решения оператора

- **#1082 (брейншторм):** GT — на существующем сервере woodev.ru, без отдельного VPS, изолированно (отдельный системный пользователь,
  rootless Docker, наружу только через nginx). **DSN вписан в каждый наш плагин** через фильтр `woodev_error_reporting_dsn` — цель:
  ошибки с сайтов КЛИЕНТОВ раньше, чем они напишут; свои сайты не мониторим; ручной DSN в wp-config отклонён. Галочка согласия — без
  изменений. Уведомления — **почтой через SMTP Яндекса** (Telegram у GT не нативный, а с сервера ещё и недоступен). Хранение — 30 дней.
- **#1090:** развилка воркера о UX повтора оплаты — вариант A (принудительный повторный выбор ПВЗ в C-3), улучшение → **#1101**.
- **#1100:** безопасной области выбора по умолчанию нет → fail-loud (выбрал воркер, подтвердили оба критика).
- Сертификат основного сайта — заменить платный на бесплатный автопродлеваемый (сделано); два мёртвых поддомена — удалить (сделано).

## Сделано

- **#1096 / PR #1103** — Codex gpt-6-luna: `chain-sync.ts` компенсирует `/forget` только для НЕприменённого select. Критик Sonnet 5.5
  ACCEPT WITH NITS: новый тест был пустым (проходил и на main) → Codex добавил проверку после `release()`; я перепроверил — без фикса
  падает. Узкий вариант той же болезни → **#1102**.
- **#1100 / PR #1104** — Sonnet 5.5: `_doing_it_wrong` + уведомление мерчанту (только при блочном чекауте) + отказ
  `woodev_pickup_unavailable` в `validate_order`. Критик Codex sol r1 **REJECT** (не пересобран `.mo`; ложная тревога для классики) →
  правка → luna r2 ACCEPT WITH NITS (проверка блочного чекаута на каждом рендере уведомления — дёшево, не мемоизировано).
- **#1090 / PR #1105** — Fable 5.1: четыре серверных дефекта (повтор оплаты писал `''` поверх id пункта; запрос корзины чистил пункт
  брошенного неудачного заказа; повтор на другом перевозчике держал старый пункт; пустые очистки писали в заказ) + две клиентские
  защиты. Критик Codex sol r1 **REJECT** — 4 воспроизведённые находки (повтор после смены адреса; повтор на другом экземпляре метода;
  запоздалый ответ затирает ручную правку улицы; исправленный сервером пункт = ошибка) → Fable: повтор принимается только на
  подтверждении, с которым заказ размещён (пункт + ПОЛНЫЙ id тарифа + адрес + населённый пункт, хранится в сессии WC; несовпадение —
  отказ и снятие с заказа; без сохранённого подтверждения — fail-closed) → luna r2 ACCEPT WITH NITS. Пробa воркера на риге против
  ветки: 16 из 16 наблюдаемых шагов совпали с main. Не проверяемо на риге: смена способа оплаты (один шлюз), неудачная оплата.
- **#1082** — GlitchTip развёрнут и открывается на `errors.woodev.ru`, регистрация закрыта, аккаунт оператора создан (пароль сменил
  он сам). Детали сервера — **только в приватных заметках оператора** (`~/Documents/woodev-vds/` на MacBook), не в репозитории:
  репозиторий публичный. Почта — за оператором.
- Карточки: **#1101** (UX повтора оплаты), **#1102** (второй выбор + размонтирование) — Бэклог / Потом.

## Ошибки сессии

- **Детали инфраструктуры боевого сервера ушли в публичную карточку #1082.** Классификатор остановил следующий такой комментарий; оператор выбрал «вычистить» — пять комментариев отредактированы
  (история правок GitHub старый текст хранит). Правило — в локальной памяти: на публичную карточку только решения и нейтральный статус.
- Принял самоответ формы AskUserQuestion за решение оператора и записал его на карточку («DSN только вручную»); оператор поправил,
  запись исправлена.
- Утверждал «Telegram-бот через webhook можно» (и на карточке из s151) — проверка исходников GT показала, что нет.
- Правка сайта через `mgrctl webdomain.edit` с частью полей уронила многословные поля (`aliases`, `dirindex`) — я читал их через
  `tr " " "\n"`. Поймано сравнением конфигов до/после, восстановлено; итоговая разница — только строки сертификата.
