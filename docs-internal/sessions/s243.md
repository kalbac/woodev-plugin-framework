## Lessons

- A required-only gate is only as good as the `required` flags: #1954 passed every test and still regressed on the rig (#1963). A rig look after
  merge caught it in minutes.
- zsh does not word-split an unquoted `$var` (`set -- $pair` gave one argument) — the first worker-start batch failed validation; no launch happened.
- Starting the watchdog with `&` inside a foreground command detaches it from notifications — always `run_in_background`.
