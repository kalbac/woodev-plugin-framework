## Root cause of the "dirty" code (measured)

Every repo has `phpcs.xml(.dist)` with the `WordPress` ruleset and CI runs it, but WPCS has **no layout sniffs**, so compressed code
reports 0 violations. Ozon had 102 `; }` lines in `includes/` against 0 in CDEK, Yandex and Russian Post; the compressed files were
Codex-written (W0/W3/W6). The framework used `phpcs.xml` (renamed to `.dist`, the convention). `woocommerce/woocommerce-sniffs` was
rejected: PHPCompatibility 9.3.5 aborts on PHP >= 8.1, it found only 4 `CommentHooks` items and has no layout sniff.
Gotcha: `wordpress-phpcs-has-no-layout-sniffs` (rode in #1518).
