## Lessons (process)

- **Merge parallel branches through a worker when PHP conflicts.** Six of the eleven merges conflicted (`class-plugin.php`,
  `CURRENT-STATE.md`, the shipment handler). Markdown-only conflicts the coordinator resolved; PHP conflicts went to a Haiku or
  Sonnet sync task in the card's worktree (merge commit, no force-push), then a fresh merge. A local merge that went red was
  reset to `origin/v2` before anything was pushed.
- **Run `--order-by=random` after every merge.** A Mockery `alias:` mock in P16's tests broke a P11 test only in the merged
  suite — gotcha `a-mockery-alias-mock-lives-for-the-whole-phpunit-process`. Every brief now requires one random run.
- **A third-round fix still needs the coordinator's eye.** P17a's round 3 widened «corrupt row → proceed» to «held lock →
  proceed», which reintroduces a barcode race; caught by reading the diff, fixed in one catch block.
- **A Codex worker can miss an `orchestration reply`** and ask the same question again; answering through `terminal send` as
  well worked.
- **One watchdog per wave.** A second watcher started for one handle had to be stopped; it had consumed nothing.
- **Sol for first critic rounds, luna for repeats and for a wave when the Codex window is past ~60 %.** The global
  `~/.codex/config.toml` swap (save, sed, launch, read the label, restore) was used for every sol run.
