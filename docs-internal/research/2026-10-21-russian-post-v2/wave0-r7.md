## Verdict

- **Order body (release 1):** domestic COD = `mail-category` `…_AND_CASH_ON_DELIVERY` + `insr-value` + `payment`; **no `goods`, no `payment-method`**. `dimension` = integer cm, `mass` = real grams, the server computes the volumetric charge (÷5000). The goods list is not part of release 1 (it exists only for ECOM_MARKETPLACE / DELIVERY_PLUS, out of scope, §4.4).
- **Order lookup:** a prefixed `order-num` is findable by exact match in both stores; reconcile stays off (§8.5) but its reference is no longer unmeasured.
- **Method ids:** only `russian_post_courier` collides, and only with a Dokan add-on abandoned since 2022 with 0 active installs. By the operator's rule (rate by real-shop probability), keep the id; if free, a one-constant rename (e.g. `russian_post_door`) removes it. If both plugins were ever active together, WooCommerce keeps one class per id and the Dokan plugin's `stripos` filter would swallow our rates.

## UNVERIFIED

- Whether the goods list is accepted (and its exact field set enforced) for ECOM_MARKETPLACE / DELIVERY_PLUS — needs an account with the product switched on (U3).
- Whether `payment-method` has any accepted value besides `CASHLESS` (`ADVANCE_PAYMENT`, `POSTAGE_STAMPS_*`, `FREE` were not tried — nothing in release 1 needs them).
- Volumetric divisor and size limits for POSTAL_PARCEL, PARCEL_CLASS_1, EMS, ONLINE_COURIER (only ONLINE_PARCEL was measured; limits not hit at 100×100×100 cm).
- Whether `backlog/search` / `shipment/search` find an order after the batch has been sent (checked-in / handed over) or archived — never done, forbidden.
- wp.org has no code search; the collision check covers the 246 plugins returned by 12 wp.org API searches (`russian post`, `russianpost`, `pochta`, `почта россии`, `russian-post`, `russian_post`, `почта`, `pochta rossii`, `ems russia`, `russian post tracking`, `russian post shipping`, `почта россии доставка`), of which six were unpacked and grepped. A plugin that never mentions Russian Post in its name, slug or description, and non-wp.org plugins (Envato, own sites), are not covered.
