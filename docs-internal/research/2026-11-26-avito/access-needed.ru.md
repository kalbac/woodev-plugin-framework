
# Авито: что нужно от вас, чтобы промерить API (26.11.2026)

Факты и источники — в [карте API](api-map.md) (на английском). Названия разделов кабинета взяты из справки Авито;
в сам кабинет я не заходил, поэтому подписи кнопок могут отличаться.

**Главное:** тестовой среды для продавцов у Авито нет (в документации не описана). Всё меряется на настоящем
кабинете, настоящими объявлениями и деньгами. Ключ «только чтение» тоже не описан: ключ даёт полный доступ к
кабинету, включая заказ платных услуг.

## Что нужно получить

| Что | Зачем | Без этого |
|---|---|---|
| Профиль ИП или юрлица с проверенными реквизитами (ИНН) | остатки и заказы Авито Доставки | не проверить две из четырёх частей первой версии |
| Тариф в «Товарах» | ключи API вообще | не начать |
| Подписка «Расширенная» | автозагрузка и остатки | не проверить фид, отчёт и остатки |
| Деньги на кошельке Авито | тариф, подписка, размещения/просмотры | объявления не будут видны |
| `client_id` и `client_secret` | запросы к API | не начать |
| 2–3 настоящих недорогих товара | объявления для проверки | не проверить публикацию и остатки |
| Включённая Авито Доставка для бизнеса | заказы, этикетки, статусы | заказы только по документации |
| Публичный HTTPS-адрес для фида | Авито само скачивает файл | локальный стенд Авито не увидит |

«Максимальная» подписка нужна только для чатов; в первой версии я их не предлагаю.

## Шаги в кабинете Авито

1. **Реквизиты.** «Управление профилем» → «Подтвердить данные» → «Я — юрлицо или ИП», ввести ИНН и систему
   налогообложения, пройти проверку. Пополнить кошелёк Авито со счёта организации (это требуется для доставки для
   бизнеса).
2. **Тариф.** Вкладка «Тариф» (или «Для бизнеса» → «Тарифы» → «Настроить тариф»), основная категория — из «Товаров».
   Для товаров это обычно «с оплатой за просмотры»: пополняется аванс, сами объявления размещаются бесплатно.
   Тариф «за успешную сделку» для проверки не советую: за отменённые продавцом заказы его могут отключить.
3. **Подписка.** «Тариф» → «Инструменты» → «Больше инструментов» → «Расширенная» → «Подключить». Списывается каждый
   месяц с кошелька.
4. **Ключи.** Кабинет Авито Pro → «Профиль и настройки» → «Интеграции и API». Появятся `client_id` и
   `client_secret`. **В чат и в репозиторий их не присылать.** Положить в файл на этом Mac вне проекта (путь назовите
   мне) или ввести самому в настройках плагина на стенде, когда он появится.
5. **Автозагрузка.** Раздел «Автозагрузка» появится в профиле после подписки. Принять правила, указать почту для
   отчётов. Расписание и ссылку на файл не заполнять — это сделаем при замере.
6. **Текущие объявления.** Если они уже есть: «Автозагрузка» → «Создать файл» → скачать XLSX и отдать мне файл
   (из него видны категории и поля; личные данные в нём — телефон и адрес — можно замазать). Если объявления сейчас
   грузит другой сервис или плагин — сказать об этом **до** замера.
7. **Тестовые товары.** Выбрать категорию, где есть доставка и «Несколько штук в наличии» (не «Животные», не
   «Водный транспорт», не «Готовый бизнес»; телефоны — только новые). Приготовить: фото JPEG/PNG, цену, адрес, вес
   и габариты, а для новых товаров — коды ТН ВЭД и ОКПД 2 (и документы, если Авито попросит).
8. **Доставка.** Раздел «Авито Доставка» (только с компьютера) → включить доставку партнёрами Авито.
9. **Адрес фида.** Согласиться на один из вариантов: ★ поддомен на wootest.ru (постоянный публичный сайт) или
   Tailscale Funnel к стенду на время замера.

## Вопросы в поддержку Авито (отправить от вашего имени)

Могу подготовить текст письма; отправка — только после вашего «да».

1. Можно ли продавать платный плагин для WordPress, который работает с API ключами самого продавца на его сайте?
   Нужна ли «регистрация приложения через службу поддержки» (п. 1.1 правил API) и кому?
2. Правила API (п. 2.7) запрещают использовать в приложении товарные знаки и фирменное название Авито. Можно ли
   писать «для Авито» в названии плагина и в меню? Что разрешено?
3. Есть ли тестовый кабинет или тестовый режим для разработчиков?
4. Можно ли оформить проверочный заказ на своё объявление со второго аккаунта (и отменить его), или это нарушение?
5. Достаточно ли «Расширенной» подписки для методов остатков и какую ошибку вернёт API без подписки?
6. Дают ли тариф «за успешную сделку» или другой тариф без аванса доступ к API?

## Что замер изменит и что будет стоить денег

- Публикация объявлений: списания за просмотры из аванса (или за размещение), пока объявления активны.
- Проверочный заказ — только после ответа поддержки и вашего отдельного разрешения: подтверждение, отмена и
  этикетка меняют настоящий заказ. Без него эти действия пойдут в первый выпуск как непроверенные (как с Ozon).
- Платные услуги продвижения я не подключаю.

## Если своего кабинета нет

Вариант — кабинет клиента с его письменным согласием, и только запросы на чтение. Помните: ограничить ключ нельзя,
«только чтение» держится на моей дисциплине. Так можно проверить список объявлений, отчёты и список заказов, но не
публикацию, остатки и действия с заказами.
