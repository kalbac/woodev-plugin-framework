# s210 — internal documentation audit

**Date:** 2026-11-02 · **Scope:** all of `docs-internal/` (root, `gotchas/`, `gotcha-index/`, `adr/`, `wiki/`, `specs/`, `research/` headers), `.ai/skills/`, and the `AGENTS.md` / `CLAUDE.md` gateways · **Kind:** contradiction map (written before any edit) and fixes · **Ground truth:** framework `VERSION = '2.0.22'` (`woodev/class-plugin.php:22`), `planned-release = 2.0.23` (`composer.json:128`), `main` at `da06e0f8`.

## Method

Five read-only readers each produced a contradiction map for one area (root + gateways, gotchas A–gitleaks, gotchas after it, ADR + wiki, specs + research + skills). This record merges them, removes duplicates (a row seen by two readers keeps one id and names the other), and gives every row a decision. Every **high** and **medium** row was re-checked against the code or the second document before the decision was set; the checks that mattered are in the last column of the verification table below. Row ids keep the reader prefix so a reader report can be matched back: `R-` root, `GA-` gotchas first half, `GB-` gotchas second half (`S0`–`S3` are its sub-slices, `M` its own rows), `AW-` ADR + wiki, `SP-` specs + skills.

Decisions: **fix** (done in this PR), **park** (needs code or an operator decision — listed under "Parked"), **reject** (the reader was wrong, or the item is a recorded, accepted gap).
