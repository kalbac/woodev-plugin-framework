# s245 — internal documentation audit + the bot-mode description

**Date:** 2026-11-25 · **Scope:** `AGENTS.md`, `CLAUDE.md`, `docs-internal/` (root, `gotchas/`, `gotcha-index/`, `adr/`, `wiki/`, `specs/`), the global `~/.agents/AGENTS.md`; plus one owner-approved addition — [bot mode](../wiki/bot-mode.md) beside the direct mode · **Kind:** contradiction map (written before any edit), then fixes · **Ground truth:** framework `VERSION = '2.1.19'` (`woodev/class-plugin.php:22`), `planned-release = 2.1.20` (`composer.json:130`), `main` at `ff46bfb9`, 80 open issues before this audit filed #1980 and 81 after (`gh issue list`), unit suite 11431 tests / 1 skipped and jest 4559 tests in 145 suites (both measured in this worktree today). Before-state tag: `docs-before-bots`.

## Method

One reader, one pass, the s220 shape. Mechanical gates first (counts, links, section presence), then a read of what changed since the s220 audit (`git diff 24b0bff2..HEAD`: 63 gotchas — 51 new, 12 modified —, ADR-013, the new marketplace wiki, 3 new specs), then the gateways, state files, `DOCS-INDEX.md`, `DOCS-SCHEMA.md` and the orchestration wiki in full. Claims were checked against the code tree, `package.json`, git tags and `gh` (card, PR and release state). Operator decisions newer than the documents were taken from session files where recorded (s224) and, where the repo had no record, from the coordinator's memory and the bots' instruction files (read only).

Decisions: **fix** (done in this PR), **list** (a handoff line or a file outside the repo that the coordinator or a bot rewrites — not edited here), **park** (needs code or an operator decision), **reject** (recorded, accepted gap).

## Cross-project learnings proposed (not written to Supermemory by this worker)

1. `[meta] A role or fleet decision recorded only in agent memory or a session file leaves the gateway docs stating the
   opposite (the 10.11.2026 «Codex is critic only» reversal stayed contradicted for 15 days) — edit the gateway in the
   same session. (as of 25.11.2026)`
2. `[meta] A spec status left «for the release session to update» does not get updated — the PR that closes the last card
   updates the Status line. (as of 25.11.2026)`
3. `[global] Orca delivers a bot message of --type status as information with no job and no reply; a bot that must act on
   it needs that rule in its own memory. (as of 25.11.2026)`
