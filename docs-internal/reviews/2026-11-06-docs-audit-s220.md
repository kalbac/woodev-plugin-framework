## Method

One reader, one pass, following the s210 shape. Mechanical gates first (counts, links, section presence, language), then a read of every file that changed since the s210 audit (`git diff 6c6f9ebe..HEAD` over `AGENTS.md`, `docs-internal/`, `.ai/`: 67 docs-internal paths, 21 changed gotchas (12 new, 9 modified), 4 wiki files, 2 ADRs, 11 skill files, 5 new specs, 2 new plans), then the gateways and root files in full. Technical claims were checked against the code with Serena (activated on this worktree; every result path was under it) and against `gh` for card/PR state. Session files `s211`–`s219` were used for facts only and not edited.

Decisions: **fix** (done in this PR), **list** (a handoff / state line the coordinator rewrites at save — not edited here), **park** (needs code or an operator decision), **reject** (the item is a recorded, accepted gap or approximate by design).
