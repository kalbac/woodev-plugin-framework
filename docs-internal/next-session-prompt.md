# Что доказано замером

1. **Для незарегистрированного слага админ-страницы `admin_init` не срабатывает никогда** —
   `wp-admin/includes/menu.php:375-382` отдаёт 403 до `admin.php:180`; зонд curl на риге: старый
   слаг 302, чужие слаги 403, без входа — логин (готча
   `admin-init-never-fires-for-an-unregistered-admin-page-slug`).
2. **Клиент страницы заказов выбирает перевозчика по `carrier` из редиректа** — текстовый зонд:
   по редиректу только строки «Реалистичной», контроль без `carrier` — обоих перевозчиков.
3. **Ядровый `plugin_basename()` разрешает имя плагина во всех четырёх симлинк-схемах** (без
   симлинка, корень, отдельный плагин, оба сразу) — ручной обход `$wp_plugin_paths` падал на
   двойном; воспроизведено критиком на реальных симлинках (#900).
4. **Mac на 64 ГБ спокойно держит три агента плюс чужую сессию** — `memory_pressure` 94% свободно.
5. **Лицензионная «коллизия» id 0 была шумом на каждом запросе** — `debug.log` рига: старый код
   1138 → 1141 за два запроса, с правкой #905 1141 → 1141.
6. **После сна Мака OrbStack может зависнуть** — `curl -m 20` вернулся через 900 с, `docker ps`
   не отвечал; перезапуск OrbStack + `npx @wordpress/env start` вернули риг с данными.

# Ловушки

1. **Сон Мака валит всё сразу** — Docker, ожидания Orca, `worker_done` воркера; на macOS нет
   `timeout`, ограничивай через `perl -e 'alarm N; exec @ARGV'` (готча
   `after-the-mac-sleeps-orbstack-hangs-and-every-rig-call-hangs-with-it`).
2. **Codex в лимите ничего не делает, а диалог «Approaching rate limits» висит поверх** — статус
   агента при этом `live`; читай экран. Останавливать — `worker-stop` после доказательства.
3. **Полный путь к `orca` — в КАЖДЫЙ бриф, и критику тоже.** В s137 первый критик потерял
   `worker_done` ровно на этом.
4. **Воркер может доказывать красноту через `git stash`** — стек общий для всех ворктри; после
   такого отчёта проверяй `git stash list`.
