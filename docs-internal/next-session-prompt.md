# ⚠️ Ловушки, купленные этой сессией дорого

1. **Тест, покрывающий хелпер, НЕ покрывает строку, которая его зовёт.** Весь #300 сводился к одной строке; шесть новых тестов звали санитайзер напрямую, и сьют из 2143 тестов оставался зелёным с откаченной строкой. Мутировать надо строку, которую тест НАЗЫВАЕТ. Пятое появление `built-on-both-sides-with-no-caller-in-the-middle`, впервые во второй форме.
2. **`Functions\expect('f')->once()->with(X)` не отвергает второй вызов с другими аргументами.** `->with()` это фильтр, а не перепись, поэтому тест, в названии которого стоит счёт или исключительность («into one notice», «fires alone»), таким способом не пишется. Захватывать вызовы через `Functions\when()->alias()` и утверждать список целиком.
3. **`woocommerce_form_field()` рисует `<label>` и для скрытых полей** — исключён только `checkbox`. Подпись для СООБЩЕНИЙ и подпись для ОТРИСОВКИ это два разных поля дескриптора.
4. **`Set-Cookie` у WordPress приходит массивом.** `count($value) === 1 ? $value[0] : $value` — так что заголовок, ради которого пишется security-фикс, самый вероятный кандидат на массив.
5. **DOM-атрибут на поле чекаута — не ваш узел.** Режимы `ajax-select2`/`related-list` пересоздают его, `updated_checkout` заменяет, две секции делят один блок конфига. Сигнал между модулями публикуется через событие, хук или серверный блок конфига.
6. **Ребейз в воркдереве невозможен из-за перманентной CRLF-грязи** в четырёх JS-ассетах: она блокирует любую операцию, требующую чистого дерева, и `git checkout --` её не убирает. Рабочий приём — `git update-index --assume-unchanged` в одноразовом клоне.
7. **Serena читает ГЛАВНОЕ дерево, которое на `main`.** Для первого круга работы в воркдереве это безобидно, для круга ПРАВОК — нет: файлы, которые правишь, как раз и отличаются. Писать всегда встроенным `Edit` по абсолютному пути.
8. **Codex на этой машине лечится установкой PowerShell 7 обычным MSI** (`winget install --id Microsoft.PowerShell`, нужен администратор). Диагноз: команды исполняются от лица локальных аккаунтов `CodexSandboxOffline`/`Online`, а Store-сборка `pwsh` для них недостижима. Пока не починено — критиком работают независимые агенты, и они окупились на каждом PR этой сессии.
9. Прежние в силе: `phpunit-defects-cache-hides-cross-test-session-leaks` (удалять `.phpunit.result.cache` перед цитированием прогона), поднятие `VERSION` на `main` публикует релиз (#285, оператор решил ждать готовности V2).
