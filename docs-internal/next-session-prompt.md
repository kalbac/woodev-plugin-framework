# Что доказано замером

Полностью — в `sessions/s126.md`. Шесть фактов, нужных сразу:

1. **`NOT IN` в `meta_query` НЕ ловит строки без меты вообще** — LEFT JOIN даёт только
   `NOT EXISTS`. Выпадающие строки обычно и есть большинство, а запрос при этом успешен.
2. **Матрица запрашиваемости фильтров (§D10):** дата, перевозчик, статус заказа, наличие трека —
   да; статус доставки — только через инверсию `status_map`, по-перевозчиково, OR на агрегате;
   **тип доставки — НЕВОЗМОЖЕН** (три перехода до зон доставки, хранимого значения нет).
3. **`is_exported()` — понятие ФРЕЙМВОРКА.** `Abstract_Shipment_Handler::export()` пишет
   `carrier_order_id`; предикат строится на нём, без частных понятий перевозчика.
4. **У пикера дат WooCommerce НЕТ «всё время».** Пресеты — Today … Last year + Custom. Список
   становится ограничен периодом навсегда; дефолт — `period=year` (решение оператора).
5. **`wc-admin`-страница подсвечивает родителя в меню НА КЛИЕНТЕ**, из `wpOpenMenu`. WordPress
   рисует меню на сервере и не видит `path`.
6. **Риг на `WPLANG=en_US`.** Английские даты и английский хром WC там — локаль, не дефект.

# Ловушки

Только новое за s126; прежнее — по тегам в `GOTCHAS.md`.

1. **`NOT IN` роняет строки без меты** — готча
   `a-not-in-meta-query-silently-drops-rows-that-have-no-meta-at-all`. Ловится ТОЛЬКО интеграцией:
   юнит-тест над аргументами запроса не видит, что с ними сделает MySQL.
2. **`grep --include` через `wp-env run` молча не находит ничего**, а WooCommerce лежит в
   `plugins/woocommerce.latest-stable`. Пустой результат читается как «этого API нет». Готча
   `grep-through-wp-env-run-loses-the-include-glob-and-the-wc-directory-is-not-called-woocommerce`.
   **Проверять проверку на заведомо существующем символе.**
3. **Интеграция — работа КООРДИНАТОРА и не необязательна.** Воркер написал верный тест, не смог
   его запустить, и дефект уехал бы в `main` на зелёном юните.
4. **Квотированный heredoc через Bash съедает обратные слэши и фигурные скобки счётчика** — Python
   падает синтаксической ошибкой, `grep -oE` ругается на «Invalid contents of {}», а большой
   heredoc обрывается на «unexpected EOF». Скрипты и длинные файлы писать инструментом Write
   (подтверждена трижды в s126).
