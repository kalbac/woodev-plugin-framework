# Ловушки

Только новое за s128; прежнее — по тегам в `GOTCHAS.md`.

1. **Убитый PHP-процесс НЕ убивает запрос в MySQL** — следующий прогон виснет на `DROP TABLE
   wp_users`. `SHOW FULL PROCESSLIST` первым делом; клиент `mariadb`.
2. **EOL врёт дважды:** инлайновая проверка даёт LF на CRLF-файле, И **переключение ветки возвращает
   `.ts`/`.tsx` в CRLF** — скрипт с якорями на `\n` молча НИЧЕГО не делает и рапортует успех.
3. **Шелл портил содержимое ПЯТЬ раз** — писать ФАЙЛОМ и ЧИТАТЬ результат.
4. **Зонд на риг — Playwright, `admin`/`password`**, конфиг в scratchpad, `NODE_PATH=…`;
   `screenshot({path})` пишет В КОРЕНЬ РЕПО; логину 60 с. **Оператора НЕ звать.**
5. **`worker-start --terminal` требует и `--worktree`.**
6. **Codex может упереться в жёсткий лимит аккаунта**; критиком тогда Fable 5.1.
