# С чего начать

Режим — **овернайт**: не блокироваться на операторе; вопрос → карточка в «Инбокс» + обратимое временное решение. Бэкенд
мержится по гейту «зелёный ПОЛНЫЙ CI + критик другой модели» (память `merge-and-take-the-next-card-without-asking`; мерж
разрешён оператором в s145 — `gh pr merge` проходит). UI — только парковать. Воркер **Sonnet 5.5** (`--model claude-sonnet-5-5`),
критик **Fable 5.1** (`claude-fable-5-1`). Codex — только если `orca account list` покажет запас (в s145 ~14 % недели).

   появилась → переносится. Критик → CI → мерж.

   «Выгрузить» НЕ меняются (закрепить тестами). PR паркуется, в теле — что смотреть на риге.
3. **#1014** — одна составная вкладка перевозчика (`Composite_Settings_Handler`, как «Доставка») + `_doing_it_wrong`. Паркуется.
