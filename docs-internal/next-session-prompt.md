# Пять корневых причин, найденных в коде (это не «спека была неправа», это дрейф реализации)

1. **У диалога нет своего размера** — высоту давал только `.woodev-pickup-map`. До монтирования карты
   модалка = полоска хедера. → T2.
2. **Панели `position: fixed`**, а у `.woodev-modal__content` есть `transform` — он и становится
   containing block. Отсюда сайдбар поверх хедера и кнопка сайдбара поверх «закрыть». → T5.
3. **Опции `SearchControl` лежали в корне аргумента**, а контролы ymaps принимают `{ data, options,
   state }` — `provider`/`layout`/`noPlacemark` молча проигнорированы, остались дефолтная плашка и
   дефолтный всемирный геокодер. → T12.
4. **У фич не задан `iconShape`** — для кастомного HTML-layout'а область клика берётся только оттуда,
   `iconImageSize` тут не работает. Клик проваливается в POI-слой, открывается карточка организации
   Яндекса. → T8.
5. **Зум — дефолтный слайдер на `left: 70`**, эталон ставит `left: 12 / bottom: 70`. → T14.

# Решение, которое было принято и отменено — не принимать заново

Черновик спеки предлагал **выбросить `SearchControl`** и звать `suggest`/`geocode` напрямую.
**Это неверно, отменено 03.08.** Оператор возразил, бандл Почты РФ
(`https://widget.pochta.ru/map/main.a7d147fb5267ec1f0932.js`) был прочитан и подтвердил его правоту:
Почта строит один `ymaps.control.SearchControl`, чей кастомный layout рисует поле, кнопку сброса,
меню результатов **и меню фильтра с бейджем**; движок используется полностью
(`search()` / `getResultsCount()` / `showResult()`), состояние фильтра лежит на этом же контроле и
слушается `ymaps.Monitor` → `objectManager.setFilter()`.

Оттуда же два факта, ломающие прежние допущения: **`ymaps.suggest` Почта не использует вообще** и
своего `provider` не передаёт — поэтому её собственный поиск и отдаёт Тольятти на «Цветной бульвар».
Наша конструкция = шаблон Почты + ограниченный `provider.geocode` Яндекс.Доставки
(`boundedBy` = границы загруженных точек, `strictBounds: true`).

Следствие: **адресный запрос по submit, а не по каждому нажатию** (как у Почты) — это снимает
причину, по которой D-6 брал `suggest` вместо `geocode`. Совпадения по загруженным точкам остаются
мгновенными на вводе.
