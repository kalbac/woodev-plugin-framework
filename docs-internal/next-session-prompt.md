# 🧠 Дизайн, принятый в разговоре — #437

В конце s84 оператор разобрал со мной ось НП. Итог — спека
`docs-internal/specs/2026-08-21-settlement-search-design.md` и карточка **#437**, которая
**поглощает #411**.

Суть: `LIST_HARD_CAP = 500` — не число, которое надо подобрать, а симптом неправильного вопроса.
Пока фреймворк спрашивает `list_localities( $scope )` («отдай всё»), выбор стоит между 3000 строк
в DOM (замер в бою: 3–5 сек на рендер по МО) и слепым срезом. Контракт для НП становится
**поиском в scope**, и крышка удаляется вместе с вопросом.

Ключевые решения: НП никогда не плоский список; фреймворк хранит регионы и 20–30 популярных НП
магазина, справочники — никогда; три способности провайдера, ни одна не про bulk; «Связанный
поиск» переопределён как «НП **требует** региона» (тип контрола не важен); режим **выводится**, а
не настраивается, переопределение — фильтром.

**PR #423 (#411) не закрыт намеренно** — подсказка про обрезку может пригодиться промежуточной
мерой, если #437 поедет не сразу. Решение за оператором.

# 🔑 Про оркестрацию — что подтвердилось

Форма из s83 держится: **воркер Sonnet, критик Codex, свою работу не принимает никто.** **Каждая**
карточка, прошедшая через критика, вернулась с чем-то настоящим. Рецепт, шаблон брифа, четыре
обязательные строки и потолки — `docs-internal/wiki/orchestrating-agents-with-orca.md`.

Пятая строка брифа окупается на всём нетривиальном: **«тебе разрешено противоречить этому брифу;
если код не согласен — прав код».** За ночь она вытащила четвёртый незакрытый AJAX-хендлер,
которого не было ни в одной карточке, pre-flight проверку, которая существовала, но не читалась, и
«базлайн устарел», оказавшееся настоящей дырой в оснастке.

**И приём, который стоит копировать:** два последних вердикта по #395 решились тем, что критик
**вызвал метод и вставил в отчёт возвращённое значение**, тогда как три предыдущих круга спорили по
чтению кода. Критик, который запускает код, стоит нескольких, которые его читают.

# ⚠️ Ловушки из прошлых сессий, всё ещё в силе

`ReflectionProperty::setValue()` — guard `setAccessible()` по версии PHP · WooCommerce определяет
страну свежего гостя ГЕОЛОКАЦИЕЙ с фолбэком `US` · `Woodev_Setting::get_value()` кэширует —
хендлер строить ПОСЛЕ подмены `get_option` · JS-тесты ИЗ BASH, никогда `npx jest` · `billing_city`
на риге — select2 старого демо §8, источник ничего не отдаёт · бэктики в `--body "$(cat <<'EOF' …)"`
съедает bash, тело писать через `--body-file` · закрывающие ключевые слова GitHub исполняются из
тела коммита буквально (гейт `.githooks` включён) · кросс-хендлерный `show_if` работает и на
сервере, но зажимать значение надо ПРИ ЧТЕНИИ · `docker exec … wp eval-file` требует
`MSYS_NO_PATHCONV=1` · читать чужую ревизию через `git show <ref>:<path>`, а `git checkout --` и
`git add -A` при живом воркере — как терять чужую работу.

**Две, на которых спотыкались этой ночью:** `@since` — это ПЛАНИРУЕМЫЙ релиз (`2.0.2`), не
`VERSION` и не инкремент на коммит (двое воркеров уехали в `2.0.3`, обоих поймали критики); и
**Serena переводит файл в CRLF** при `replace_symbol_body` / `insert_before_symbol` — смотри
`git diff --stat` перед `git add`.
