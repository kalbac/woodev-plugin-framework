# Что доказано замером

1. **Зелёный юнит-сьют НЕ доказательство там, где наш код встречается с чужим контрактом.** Круг 1
   по #551: шесть сфальсифицированных тестов, `composer check` 2826/6913/66, 19 зелёных джоб — и
   `resolve_key()` возвращал **Галисию (Испания) вместо Москвы**, одну и ту же чужую запись для двух
   РАЗНЫХ ключей. Код был безупречен; сломан был провайдер, а тесты его мокали. Поймал только
   риг-замер. Готча `a-mocked-provider-proves-the-mock-not-the-contract`.
2. **У `/v2/location/regions` НЕТ параметра `region_code`** — только `country_codes`,
   `fias_region_guid` (deprecated), `size` (по умолчанию 1000), `page`, `lang`. `region_code` — у
   `/location/cities`. Фикстура слала несуществующий параметр, он отбрасывался, и `$rows[0]`
   неотфильтрованной страницы = Галисия. **Тот же ложный факт стоял в докблоке, и на нём была
   объявлена `CAPABILITY_RESOLVE_KEY`.** Готча
   `the-fixture-docblock-asserted-an-api-parameter-that-does-not-exist`.
3. **Провайдер матчит по ПРЕФИКСУ, локальное сужение популярных — по ПОДСТРОКЕ.** Поэтому слияние
   #539 видно только на терминах из середины слова: `тово` → Бутово, `ино` → Репино, а провайдер по
   ним не отдаёт ничего. Пригодится для любого будущего риг-прохода по этому полю.
4. **«Москва» → «Москва, Россия» после поиска — не наш дефект.** `/suggest` и `/location/cities`
   подписывают одну локальность по-разному; популярные засеяны через второй путь.

# Ловушки

1. **Ветка PR может быть отрезана ДО половины работы, а `mergeable=CLEAN` этого не скажет.** #547
   был на 6 коммитов позади и правил тот же файл, что уже смерженный #550. Перед риг-проходом:
   `git log --oneline HEAD..origin/main`, и если не пусто — ребейз ПЕРЕД тем, как звать оператора.
2. **Проверять отдаваемое ригом надо В КОНТЕЙНЕРЕ, а не на диске.** Путь внутри —
   `/var/www/html/wp-content/plugins/woodev-test-shipping-method/…`, и структура там НЕ повторяет
   репозиторий: фикстура лежит в корне плагина, фреймворк — под `woodev/`.
3. **Джоб не всегда 20.** «Markdown Lint» запускается только при изменении `**.md`, поэтому у чисто
   кодового PR их **19**, и это полный набор. Считать pending, а не до двадцати.
4. **`HTTPError: 429` на `npx wp-env start` — инфраструктура, не код.** Контроль: другие
   интеграционные джобы на ТОМ ЖЕ коммите. `gh run rerun <id> --failed`. Но лог прочитать — s87
   принял настоящий провал теста за такую же флакость.
5. **`orca worktree rm` отказывается удалять ворктри из-за CRLF-грязи, с которой она и рождается.**
   Нужен `--force`, но **список путей в ошибке читать обязательно**: для любого другого списка
   `--force` уничтожает настоящую работу.
6. **`SESSION-LOG.md` теперь индексирует только s50+**; s0–s49 — в
   `archive/session-log-through-s49.md`, и гейт научен считать сессию достижимой через архив, **на
   который индекс ссылается**. Убрать ссылку — краснеет 48 сессий (проверено фальсификацией).
