# Что доказано замером

1. **Карточка может быть починена и не закрыта месяцами.** #289 закрыл PR #291 через ДЕНЬ после
   заведения; восемнадцать дней она читалась как «недостижимо». В этом весь смысл #644.
2. **«1789 спрятанных нарушений» — не то, чем звучит:** 1397 длина строки, 355 косметика, **37**
   всё остальное, настоящих девять. `WordPress.Security.SafeRedirect`, которым пугал прошлый
   хендофф, — **одно** осознанное вхождение, объяснённое прямо над вызовом.
3. **Погашенное `exclude-pattern` правило НЕЛЬЗЯ оживить флагом**, свойства сниффа из CLI не
   задаются, `tab-width=4` меняет ответ: 1002 против 1393. Готча.
4. **`DisallowLongArraySyntax` даёт ERROR** и `phpcbf` чинит все 640; «проход руками на 648 мест»
   не подтвердился. **`array()` → `[]` почти не влияет на длину строк** (1002 → 999).
5. **§5 ссылается на §17 за GUID-регистрацией, а она в §18.** Вторая такая ошибка в одном файле:
   искать надо ссылки одного раздела на другой.

# Ловушки

1. **`git diff --name-only` подмешивает предупреждения git из stderr и называет файлы, которых
   никто не трогал.** В s110 попались ДВА агента подряд: координатор и Codex-критик, завернувший
   чистую правку из-за семи несуществующих изменений. Предупреждения одноразовые, поэтому повтор
   «чинит» проблему, которой не было. Авторитет — `git status --short`. Готча.
2. **Тесты, сверяющие исходник КАК ТЕКСТ, ломаются от механического переформатирования** — 633
   замены дали 47 падений; а подмена функции на WP-обёртку внутри ПРИВАТНОГО метода ломает сьюты,
   которых `grep` не находит. Надёжна только полный прогон. Готча.
3. **`--` внутри XML-комментария делает `phpcs.xml` невалидным** — проверять разбором как XML.
4. **Хвост буфера терминала обрезан:** отсутствие фразы в `terminal read` не значит, что бриф не
   доехал. Смотреть длину буфера прежде вывода.
5. **`AGENTS.md` — 28.0 из 28.0 КБ, `CURRENT-STATE.md` — 27.9 из 28.0, этот файл — у своего
   потолка.** Следующая вставка обязана что-то вытеснить. `SESSION-LOG.md` расщеплён в пятый раз
   (s90–s99 → `archive/`), дальше очередь s100–s109.
6. **Файл со СМЕШАННЫМИ концами строк заставляет phpcs жаловаться на ПРОБЕЛЫ.** Готча
   `serena-replace-content-eol-flip`.
