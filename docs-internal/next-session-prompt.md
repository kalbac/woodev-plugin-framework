   (`tests/_fixtures/`), реестр `Location_Provider_Registry`; регион + населённый пункт через API СДЭК (песочница), `CAPABILITY_LIST`

   Воркер Sonnet 5.5, критик luna (sol — если спорно). Приёмка СДЭК после слияния.
2. **#1214 — коробки магазина по настоящей раскладке** (фреймворк, переиспользовать `Woodev_Packer_Virtual_Box` / `get_placement()`):

   `Constraint_Checker`, раскладка в ячейку) → плагин (маппер). Видимый покупателю текст причины — **запарковать на его взгляд**.
4. **edostavka#52 — вехи 2–5** (`Lifecycle::trigger_milestone`). Это уведомления в админке — **реализовать и запарковать** на его взгляд.
