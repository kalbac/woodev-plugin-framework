# Что доказано замером

Подробности — `sessions/s134.md`.

1. **CI краснела не случайно.** По всем 600 прогонам `ci.yml`, первый прогон на ветку, без
   dependabot: **95% → 96% → 73%** по неделям. Семь красных из восьми с 05.09 — два семейства гейтов
   про ГЕНЕРИРУЕМОЕ (каталог #791/#771, assets parity). Закрыто `.githooks/pre-push` (#871).
2. **`update_order_meta()` ветвится по датастору** — под HPOS пишет через объект, на легаси-CPT мимо
   него. Строка, пересобранная после действия, устаревает ТОЛЬКО на CPT. Готча.
3. **`_n()` с русским msgid**: в PHP верен, если запись несёт все три формы (`wp eval`: 1/2/5/21 все
   верны под ru_RU); в JS не чинится никогда — `wp_set_script_translations()` не вызывается нигде.
   Старая готча s7 переписана: её посылка «каталога нет» была мертва.
4. **#860 доказан откатом.** Интеграционный тест на пустой `carrier_order_id` проверен на падение:
   на старой клаузе строка попадает в ОБЕ стороны фильтра.
5. **Глифы действий — общий набор**, а не вкус одного плагина: edostavka и Почта совпадают
   кодпоинт в кодпоинт (`\f317` / `\f463` / `\f14f`).

# Ловушки

Только новое за s134; прежнее — по тегам в `GOTCHAS.md`.

1. **Зонд, чей селектор не нашёл ничего, «проходит»** — «нет плохих записей» верно на пустом
   множестве. Четыре раза подряд. Готча `a-probe-that-finds-nothing-passes`.
2. **`TableCard` не рендерит `<thead>`** — заголовки это строка внутри `tbody` с
   `role="columnheader"`. Поэтому ожидание `tbody tr` выполняется на скелете, ДО появления данных.
3. **Фиксированная пауза вместо ожидания состояния** дважды показала работающую модалку сломанной.
4. **`&--modifier` внутри составного селектора SCSS** приклеивается к последнему классу, а не к
   базовому. Компилируется молча.
5. **`tsc` ловит то, что проходит и в jest, и на риге** — `icon={'upload'}` не удовлетворяет
   `IconType`, хотя рисуется верно.
6. **Читать КОД ВОЗВРАТА гейта, а не хвост вывода.** `tail -3` у `;`-цепочки скрыл красный
   `lint:i18n`, и он уехал в push.
7. **Слот `.woocommerce-table__actions` растягивает своих детей** — два контрола пришли по 1146px и
   встали друг под другом. Отдавать слоту ОДИН элемент и раскладывать внутри самому.
8. **Зонды без `PROBE_OUT` пишут в корень репозитория.**

⚠ **Читать доску по полю «Приоритет».** Считать с `--limit 300` для issue и **`--limit 1000` для
`project item-list`**.
