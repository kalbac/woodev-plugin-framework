# ❗ Что тянет за собой #380

Оно **отменяет решение S2** спеки (помечено в её шапке): осей оказалось две, а не одна.

Два подводных камня — расписаны в карточке, но их легко не заметить:

1. **Имена опций не должны переезжать вместе с полями** (ADR-005). Сейчас это `woodev_location_*`,
   потому что регистрирует `Location_Settings`; секцию можно собрать из двух хендлеров —
   `Composite_Settings_Handler` это умеет.
2. **«Обычное текстовое поле» для НП — новое состояние**: сегодня все три значения `field_mode` это
   способы подсказывать. И оно выключает запись уровня НП, на которой держатся ключ хранения ПВЗ и
   `within`-скоуп адреса (§4.2 спеки прямо на это опиралась). **Вопрос оператору сформулирован в
   #380** — до ответа делать пункты 1, 4, 5, 6.

# ✅ Что из требований оператора УЖЕ работает — не переделывать

Проверено по коду, не по памяти:

- «включить «Подсказки для адреса» можно только если кто-то отдаёт адрес И настроен» —
  `is_address_suggestions_available()` → `is_level_servable()` → `resolve_provider_for_level()`,
  который проверяет `is_configured()` и у активного, и у фолбэка;
- **ненастроенный провайдер НЕ исчезает** из списка выбора;
- **провайдер без своих полей возможен** — `test-list` это доказывает;
- **цепочка цвета карты уже «магазин → карьер → фреймворк»** с автоподбором контраста; не хватает
  только вывода существующего поля на вкладку (см. #379);
- **`show_if`** (ADR-008) с серверным enforcement — механизм для всей динамики уже есть.

  (`.select2-container--open` → `previousElementSibling.id`);

# ⚠️ Ловушки, всё ещё в силе

1. `perl` молча не мутирует CRLF-дерево — через `Edit`.
2. `ReflectionProperty::setValue()` — guard `setAccessible()` по версии PHP.
3. WooCommerce определяет страну свежего гостя ГЕОЛОКАЦИЕЙ с фолбэком `US`.
4. `Woodev_Setting::get_value()` кэширует — хендлер строить ПОСЛЕ подмены `get_option`.
5. JS-тесты ИЗ BASH; `git add -A` подметает чужое.
6. Стековые PR: `stacked-pr-github-mechanics` (там же — чистка веток после squash: авторитет это
   статус PR, а не `git cherry`).
7. `billing_city` на риге — select2 старого демо §8, источник ничего не отдаёт. Заказ оформлять
   POST-ом на `/?wc-ajax=checkout`.
8. Бэктики в `--body "$(cat <<'EOF' …)"` съедает bash — тело писать через файл (`--body-file`).
9. **Закрывающие ключевые слова GitHub исполняет из ТЕЛА коммита буквально — даже в пересказе и в
   кавычках.** Сработало дважды подряд на #370, второй раз — в коммите, который эту ловушку
   документировал и процитировал фразу. Про чужую карточку писать «закрывается реализацией #NNN»,
   номер без глагола. После пуша, упоминающего чужие номера, проверять `gh issue view <N>`.
