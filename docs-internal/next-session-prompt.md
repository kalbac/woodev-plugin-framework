# Ловушки

1. **В определении для `Woodev_Loader::register()` НЕЛЬЗЯ использовать константу фреймворка.**
   Массив вычисляется до того, как `register()` подключит автолоадер, поэтому
   `PLATFORM_WOOCOMMERCE` даёт фатал. Передавать литерал `'woocommerce'`. Готча
   `a-loader-definition-cannot-use-a-framework-class-constant`. Там же: поле называется
   **`framework_version`**, а не `version` — Rule 3 говорила неверно до s115.
2. **`gh project field-create` может записать русские опции МОЙБАКЕ молча, с кодом 200**, и это
   переживает сессию. Причина НЕ установлена: тот же вызов на доске №6 отработал верно. Писать
   через `gh api graphql` и читать значение обратно С СЕРВЕРА; починка через `updateProjectV2Field`
   меняет ВСЕ id опций. Готча `git-bash-mangles-cyrillic-in-curl-arguments`.
3. **`@since` в новом коде — `2.0.2`.** Гейт (#752) сканирует только `woodev/`, значит **писать
   правило в КАЖДЫЙ бриф.**
4. **Док-гейты сработают, и не по одному разу.** В s115 резали `CURRENT-STATE.md` трижды и
   `AGENTS.md` дважды, строку индекса `GOTCHAS.md` — один раз (потолок 400 символов). Вытеснять
   ИСТОРИЮ и пересказ, не живой факт и не номера обязательств.
5. **Прежде чем брать карточку — сверить её с кодом.** В s115 это переопределило целый шаг пилота.
6. **`gh project item-list` по умолчанию отдаёт 300** — всегда `--limit 1000`.
7. **Ворктри стартуют грязными с СЕМЬЮ CRLF-файлами**; удалять только через Orca.
8. **Serena игнорирует `tests/`, `docs/` и др.** — правило с исключением в `AGENT-RULES.md`.
9. **`gh auth setup-git` на этой машине ВЫПОЛНЕН** (проверено 04.09.2026), пуши идут. Проверять
   `git config --global --get-regexp credential` до первого пуша всё равно.
