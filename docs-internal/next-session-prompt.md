# Что доказано замером

1. **Владение методом ПВЗ из хендлера вывести НЕЛЬЗЯ.** `Shipping_Method::get_plugin()` —
   `abstract protected`; токен хендлера со списком его методов не связан:
   `woodev_realistic_shipping` против id плагина `woodev-realistic-shipping`.
2. **`private static` в классе, который каждый плагин строит себе сам, отвечает за ФЛОТ** — флаг
   «уже сделал» проверяет только первый плагин, молча.
3. **Слой `checkout/` конфликты билдера РЕПОРТИТ, а не бросает:** 17 `_doing_it_wrong()` против
   одного `throw`, и тот — провал поиска.
4. **Адресация ПВЗ идёт по КЛЮЧУ** (`test-cdek:44`) у правильно подключённого перевозчика, а без
   плагина в `Pickup_Handler` молча откатывается на имя из DOM.
5. **Модалка ПВЗ не шлёт `locality`, пока регион и НП НЕ СОГЛАСОВАНЫ** — значения `select`'а региона
   ЗАГЛАВНЫМИ, строка обычного регистра делает поле пустым и параметр исчезает.
6. **`test-cdek` — клиент живого тестового контура СДЭК**, не фикстурный словарь. Греп по файлу НЕ
   говорит, какие города он знает.

4. **Тело PR закрывает карточки ЧЕРЕЗ ОТРИЦАНИЕ.** Шаблон `Refs #N — <что осталось>` и проверка
   после КАЖДОГО мержа: `gh issue view N --json state`. В s113 сработало пять раз подряд.

   не попадают. Всегда `--limit 1000`.

   `git checkout stash@{0} -- <файлы>`.

8. **Ворктри стартуют грязными с СЕМЬЮ CRLF-файлами**; удалять только через Orca.
