# Что доказано замером

1. **#541 — асимметрия рендереров, не очередь.** Перехват до загрузки, инкогнито: клик `+0`,
   `→ /list +4 мс`, **спиннер `+10 мс`** (было `+10 558`), `← /list +9 724 мс`. Контроль с
   откаченной правкой на +800 мс: спиннера нет, `aria-disabled` = `null`.
2. **Ранняя отрисовка в ajax-транспорте select2 стоит ОБОИХ честных состояний.** Пустой список
   читается как «не найдено» (`noResults` знает только «пуст ли»), а ЛЮБОЙ `success()` снимает
   строку загрузки (`append()` начинается с `hideLoading()`).
3. **Поиск НП — предпосылка регистрации провайдера, а не capability.** `suggest()` объявлен на самом
   `interface-location-provider.php:335`. Возможностей сегодня четыре: `list`, `locate`,
   `normalize`, `resolve_key`.
4. **Фреймворк уже спрашивает ровно «подстрока + scope».** С рига:
   `/location/suggest?q=Пушк&level=settlement&country=RU&within=test-cdek:r82`.
5. **`woodev_location_allow_custom_settlement` на риге = `no`.** Хендофф s93 писал `yes` — неверно.
6. **`/suggest` 6–10 с, `/select` 13,6–14,1 с, `/list` для холодного региона 9,7 с.** Ждать по факту
   появления строки, никогда по таймеру.

# Ловушки

1. **Закрытый PR с удалённой базовой веткой восстановить НЕЛЬЗЯ** — `gh pr reopen` требует живую
   базу, `gh pr edit --base` требует открытый PR. Мержить базу стека БЕЗ `--delete-branch`,
   перенацелить нижний PR, ветку удалить последней. Готча `stacked-pr-github-mechanics`, Symptom 5.
   ⚠ Готча существовала, и я её не прочитал перед мержем — перед мержем стека читать
   `[tooling/git-merge]`.
2. **`gh pr checks` в первые секунды показывает ОДНУ джобу.** Ждать 20 джоб И ноль pending.
3. **Хук `language.noResults` спрашивать ВО ВРЕМЯ отрисовки, а не после возврата транспорта** —
   иначе тест не отличает верный порядок от неверного и пробник остаётся зелёным.
4. **Считать готчи по `ls gotchas/*.md` нельзя** — там лежит `README.md`. Верить гейту.
5. **Изолированный контекст Chrome + `initScript` ловят холодный путь.** Но контрольный `fetch` из
   консоли ПРОГРЕВАЕТ серверный кеш — контроль гонять в отдельном контексте и ПОСЛЕ замера.
