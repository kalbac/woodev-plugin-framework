# Ловушки

Только новое за s123; прежнее — по тегам в `GOTCHAS.md`.

1. **Квотированный heredoc через Bash-инструмент СЪЕДАЕТ обратные слэши.** `'\\'` доезжает как
   `'\'`, а PHP сообщает об ошибке **на тринадцать строк ниже** повреждения, на невиновном коде.
   Писать скрипты инструментом Write; литеральный слэш — `chr( 92 )`. Готча
   `the-bash-tools-quoted-heredoc-still-eats-backslashes`.
2. **`docker exec` с абсолютным путём контейнера ловит тот же MSYS-переписыватель**, что и
   `wp-env run`: `Could not open input file: C:/Program Files/Git/var/www/...` читается как сломанный
   `vendor`. `MSYS_NO_PATHCONV=1`. И **`composer test:integration` на хосте не может работать в
   принципе** — нет `WP_TESTS_DIR`, падает `Class "WP_UnitTestCase" not found`, что читается как
   регрессия бутстрапа. Рабочая команда координатора — в готче
   `wpenv-windows-gitbash-path-mangling`.
3. **База, ПРИСВАИВАЮЩАЯ поле, которое подкласс уже заполнил, теряет его молча** — и прячется тем,
   что все существующие подклассы объявляют ровно то, что присваивание возвращает. Тест на такое
   надо писать значением, которого база НЕ производит. Готча
   `a-base-constructor-that-assigns-what-the-subclass-just-set`.
4. **`gh project item-list --limit 200` молча отдаёт не все карточки** — на доске их больше вместе с
   закрытыми. Брать `--limit 1000` и пересекать с `gh issue list --state open`.
