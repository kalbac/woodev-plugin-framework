# Что доказано замером

Полностью — в `sessions/s125.md`. Шесть фактов, нужных сразу:

1. **Агрегат по перевозчикам — ОДИН запрос** (`meta_query` `relation => OR`) на HPOS. Условие #694
   закрыто.
2. ⛔ **И этого недостаточно.** Риг на **HPOS**, интеграционное окружение на **легаси CPT**, где
   `wc_get_orders()` не поддерживает `meta_query` вовсе: `_doing_it_wrong` с 9.2 и **нефильтрованный
   результат**. Готча `wc-get-orders-drops-meta-query-on-the-legacy-cpt-datastore`. **Всё, что
   трогает запросы заказов, мерить на ОБОИХ.**
3. **Семь «общих» колонок общие не одинаково:** `customer` и `payment` — байт в байт одинаковый код
   у двух плагинов, а `status` у каждого свой словарь. Отсюда канонический статус в объёме.
4. **`get_delivery_type()` абстрактен на самом `Shipping_Method`** — тип объявляет каждый метод, а
   `instanceof` по трём подклассам классифицировал бы половину как «неизвестно».
5. **Путь сборки B — единственно возможный:** `@woocommerce/components` и их webpack-плагина нет ни
   в `node_modules`, ни в `package-lock`; замер до/после показал, что остальные пять бандлов не
   двигаются.
6. **Встроенный браузер Orca работает, расширение Chrome — нет.** `orca tab create` / `goto` /
   `screenshot`; сессию логинит оператор.

# Ловушки

Только новое за s125; прежнее — по тегам в `GOTCHAS.md`.

1. **`wc_get_orders()` роняет `meta_query` на легаси-CPT и всё равно отдаёт успешный результат** —
   готча `wc-get-orders-drops-meta-query-on-the-legacy-cpt-datastore`.
2. **Свежий ворктри рождается ГРЯЗНЫМ на четырёх JS-файлах** (CRLF-блобы против нового
   `.gitattributes`); `git checkout --` не помогает, и это подставляет тот форматтер, который
   запускали последним. Готча `a-fresh-worktree-is-born-dirty-on-four-js-files`. **Никогда
   `git add -A`.**
3. **`npm run test:js` — одна из ПЯТИ команд джобы `JS Tests`**; остальные четыре гейтуют
   сгенерированные артефакты и правило «новый файл под `src/` — TypeScript». Готча
   `npm-run-test-js-is-not-the-whole-js-gate`.
4. **Запись `.tsx` в build-скрипте даёт `index.tsx.js`** — wp-scripts именует чанк через
   `basename(path, '.js')`. Готча `wp-scripts-names-a-chunk-from-basename-minus-js`.
