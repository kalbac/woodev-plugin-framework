# Что доказано замером

1. **WC 9.9 и 11.1: нет поддерживаемого способа сделать штатный Postcode/Address необязательным только для ПВЗ на блочном
   чекауте** — клиент копирует локаль страны при инициализации модуля (`prepare-form-fields.ts:74` в 11.1, `:70` в 9.9).
   Исследование: `research/2026-10-05-block-checkout-pickup-core-fields.md`.

   устаревших, без него 4/8 (s154, волна 2). Готча `woocommerce-starts-the-cart-store-from-localstorage-and-skips-the-page-s-own-cart`.
3. **Детектор «ожидания» по сравнению `getCartData()` с `getCustomerData()` пуст** — в 9.9 и 11.1 оба читают одно состояние
   (критик #1110 r3 по исходникам).
