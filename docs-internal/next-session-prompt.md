# 🎯 Первым делом: PR #345 (#337) ждёт только глаз

Всё остальное сделано и смерджено. По #345 нужна ровно одна вещь — **визуальная проверка
оператором**, потому что это UI.

Поле адреса блокируется, пока не выбран НП. Правило ровно в той форме, в какой оператор его сузил:
блокировка включается, только когда (1) в цепочке есть И поле НП, И поле адреса, И (2) провайдер
даёт подсказки уровня `address` для страны этого поля. Во всех прочих случаях — обычный инпут.
Ничем не поясняем: ни `title`, ни aria, ни подписи.

**Вкусовая развилка, на которую он должен ответить:** сила визуального сигнала. Сейчас приглушение
`opacity: .55` + `cursor: not-allowed`. Скажет «заметнее» — добавить фон (и это единственная
осмысленная правка, всё остальное проверено).

Как посмотреть: `http://localhost:8973/?add-to-cart=12` → `/classic-checkout/` → правая колонка
(Ship to a different address), поле **Street address** приглушено, пока не выбран **Town / City**.

**Дерево уже на нужной ветке** — не переключай его, пока он не посмотрит (готча
`rig-serves-the-working-tree-branch-switch-reverts-fixes`).

# Что теперь есть на риге, чего не было

**Второй живой провайдер локаций — СДЭК** (`test-cdek`, тестовый контур `api.edu.cdek.ru`).
Фикстура: `tests/_fixtures/woodev-test-shipping-method/class-test-cdek-location-provider.php`.
Ключи лежат в wp-config контейнера (`WOODEV_TEST_CDEK_CLIENT_ID`/`_SECRET`), в репозиторий не
попадают.

```bash
wp option update woodev_location_active_provider test-cdek   # вернуть: dadata
```

Это делает проверяемым то, что раньше проверялось только против собственных допущений: поуровневый
арбитраж, кросс-провайдерный `within`, разделение пространств ключей. **#333 и #346 теперь можно
брать вживую, а не по коду.**

Две вещи, которые стоит знать до того, как начнёшь ими пользоваться:

1. **`levels[RU].address = true` при активном СДЭК — это НЕ баг.** D15 резолвит провайдера ПОУРОВНЕВО
   и падает на DaData. `levels` честно описывает возможности СЛОЯ, а не активного провайдера. Чтобы
   получить по-настоящему необслуживаемый уровень — убери DaData (константу И опцию: сидер вернёт
   опцию из константы) или возьми страну без адресного покрытия (AM/AZ/KG/TJ/TM). Готча
   `a-level-served-can-come-from-the-fallback-not-the-active-provider`.
2. **Кросс-провайдерный `within` работает через КОМПОНЕНТЫ, не через ключ.** `build_scope()`
   резолвит `within` по цепочке покупателя в реальную запись, провайдер читает
   `parent_components()`. Никакого слоя трансляции ключей строить не нужно. Готча
   `a-cross-provider-within-is-handed-over-as-components`.

# ⚠️ Ловушки, купленные этой сессией

1. **`disabled` сам по себе — не сигнал.** Правило `input` у темы стирает серение браузера, и
   заблокированное поле выглядит как обычное, просто не принимает ввод. Это читается как «сломано»,
   а не «заблокировано». Нужен класс + своё правило (приглушение + `cursor`), но по-прежнему без
   единого пояснения. Готча `disabled-alone-is-not-a-visual-signal`.
2. **Прежде чем чинить «пустой ответ» — перепроверь замер.** Дважды за сессию пустой список
   подсказок оказывался гонкой с дебаунсом, а не дефектом. И синтетические `input`-события после
   перерисовки чекаута иногда не доезжают до виджета, а доверенный ввод (`fill`) доезжает — если
   меряешь UI, меряй доверенными событиями.
3. **Git Bash на Windows коверкает кириллицу в аргументах curl**, а API отвечает голым 400 и 500 —
   выглядит как его вина. Кодируй проценты руками либо гоняй пробник из контейнера через
   `wp eval-file`. Готча `git-bash-mangles-cyrillic-in-curl-arguments`.
4. **Тест на бэкстоп нельзя строить на пресете `Pickup_Field`** — у него свой condition-spec
   `required`, из-за которого блокирует пофайловый цикл и маскирует поведение бэкстопа. Голый
   `mark_pickup_slot()`.
5. Прежние в силе: поднятие `VERSION` на `main` публикует релиз (#285),
   `rig-serves-the-working-tree-branch-switch-reverts-fixes`,
   `phpunit-defects-cache-hides-cross-test-session-leaks`,
   `powershell-drops-the-roots-flag-from-the-jest-command` (JS-тесты гонять из bash),
   `git add -A` подметает чужое — перечислять файлы явно.
