# Первое действие — #517, и только потом мерж #509

**Решение оператора: сперва `onAbandon`, потом мерж.** Смержить #509 первым значит осознанно
расширить блокировку покупателя с магазинов `default_locality_policy = off` на магазины с `fixed`, а
#350 было решением ровно про то, что покупателя блокировать нельзя.

**Что чинить.** `entry.unresolved[level]` пишется в одном месте — `onAbandonFor()`
(`location-cascade.js:2818`), подключённом через примитив `options.onAbandon` (`:3015`).
`location-select-modes.js` его не вызывает НИ РАЗУ, и комментарий на `:3013` это прямо разрешает.
Значит в режимах «Список с поиском» (`ajax-select2`) и «Предустановленный список» (`related-list`)
поправки #350 не существует, и покупатель из городка, которого у провайдера нет, после #509 не
сможет оформить заказ.

Звать `onAbandon` в том же случае, что и базовый typeahead: **завершённый поиск по НЕПУСТОЙ строке
не дал ни одного результата.** Не при пустой строке, не при отменённом запросе, не при ошибке
транспорта — иначе замок снимется там, где покупатель просто не дописал название.

**Контроль обязателен:** к тесту «после пустого результата адрес разблокировался» — пара «после
результата с подсказками — нет». Эта сессия трижды получила зелёный тест, который не мог упасть.

Потом — смержить #509 (уже зелёный по всем 18 проверкам и проверен на риге до/после).

# Ловушки — самое дорогое из s91

1. **`WP_UnitTestCase` переписывает `CREATE TABLE`/`DROP TABLE` в `TEMPORARY`, а `SHOW TABLES`
   временных таблиц не показывает.** `DROP` отчитывается успехом, чтение отвечает про другую,
   настоящую таблицу. Готча `wp-integration-tests-rewrite-create-and-drop-table-to-temporary`; там же
   вторая половина — `tearDown()` обязан дропнуть И ПЕРЕСОЗДАТЬ.
2. **После #506 существующему чекауту нужен `composer dump-autoload`** — иначе девять «class not
   found» в файлах, которых никто не трогал. Ворктри копируют `vendor`, так что два ворктри на одной
   ветке могут разойтись. Готча
   `a-widened-autoload-classmap-needs-dump-autoload-in-every-existing-checkout`.
3. **PR с конфликтами — `DIRTY`, и GitHub НЕ планирует на нём `pull_request`.** Тишина CI там — это
   конфликт, а не затык очереди. «Assets build parity» при этом молча остаётся на старом коммите.
4. **Codex не может быть критиком в ворктри Orca** (WSL-git против `gitdir: D:/…`). Канарейка первой
   строкой брифа сработала — он остановился и не стал выдумывать ревью.
5. **`git checkout -- <файл>` после мутационной проверки откатывает файл целиком**, включая
   несвязанную работу в нём.
6. **Базовая цифра юнитов на `main` — 2701 / 66 skipped, а не 2718.** jest — 1380. Сравнивать
   skipped, не ассерты.
