# ⚠️ Ловушки, купленные дорого

1. **Перед тем как процитировать локальный интеграционный прогон — удали `.phpunit.result.cache`.**
   `phpunit.xml` задаёт `executionOrder="depends,defects"`, поэтому залежавшийся кэш переставляет
   ранее-красные тесты вперёд того, что их портит. На ветке задачи 15 из-за него КАЖДОЕ заявление
   «интеграционный сьют зелёный», включая написанное в описание PR, было ложным при уже красном CI.
   Матрица версий WordPress выглядела очевидным подозреваемым и оказалась ни при чём: все три леги
   проходят с кэшем и падают без. Готча `phpunit-defects-cache-hides-cross-test-session-leaks`.
2. **Зелёный сьют говорит о фиче ровно столько, сколько его тесты реально исполняют.** Арбитраж
   #294 был мёртв в конфигурации по умолчанию при 2012 зелёных тестах, потому что каждый тест
   подменял шов `wc_states()` фикстурой и ни один не исполнял тело метода. К каждому шву,
   добавленному ради тестируемости вызова WooCommerce, нужен ОДИН тест на реальное тело.
3. **Замер может отменить решение, принятое по предыдущему замеру** — за сессию это случилось
   дважды. `billing_state`: опаковый ключ плох (остаётся в данных заказа навсегда), человеческая
   подпись тоже плоха (WooCommerce поднимает регистр и ломает совпадение с опцией); верна третья
   форма — `wc_strtoupper(trim(подпись))`.
4. **Codex на этой машине не запускается вовсе** — песочница Windows отказывает в создании
   процессов, он честно возвращает «проверить не могу». Критиком выступал отдельный агент, и он
   окупился на КАЖДОМ из четырёх PR. Проверять надо факт ПРОГОНА, а не наличие ответа.
5. **Пишущие инструменты Serena резолвят пути в главное дерево** независимо от того, в каком
   worktree работает агент. Для чтения безопасна; для записи в worktree — только встроенный `Edit`
   с абсолютным путём. Один раз это развезло правки по двум деревьям.
6. **`git add -A` в свежем worktree** подметает нормализацию CRLF→LF чужих JS-ассетов.
7. **`npm run test:js -- --roots "<rootDir>/tests/js"` из PowerShell не работает** — только из bash.
8. **Поднятие `VERSION` на `main` публикует релиз** (тег + CHANGELOG + GitHub Release с ZIP) — #285.
9. Готчи в силе: `rig-serves-the-working-tree-branch-switch-reverts-fixes`,
   `array-cast-of-get-states-false-is-not-empty`, `wc-uppercases-the-posted-state-and-flips-the-map`,
   `a-locality-display-name-is-not-an-identifier`, `guest-session-write-needs-the-cart-cookie`.

# Как оператор работает — что подтвердилось в s71

Он отвечает на развилки пачкой и уходит, отдавая остальное на автономию: четыре ответа сняли все
блокировки на ночь. Дважды поправил меня по существу процесса — **не просить у него проверку того,
что он физически не может проверить** (формулировка под embedded-режимом) и **не останавливать
работу ради ревью, которое ничего не блокирует**. Риг проходит сам и подтверждает быстро («всё
проверил, всё работает»), поэтому визуальный PR стоит доводить до зелёного и звать, а не держать.
