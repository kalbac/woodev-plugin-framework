# Что доказано замером

Подробности — `sessions/s130.md`.

1. **Бейдж без кеша: 18 запросов к заказам и 1675 мс на КАЖДУЮ загрузку админки; с кешем — 0 и
   0.2 мс.** Восемнадцать, а не три: `wc_get_orders()` с постраничностью делает несколько SQL на
   вызов. Снятый SQL — шесть присоединений к мете на ДВУХ перевозчиках.
2. **Бейдж сверен со страницей СКВОЗНО**, через её собственный REST, а не через тот же код:
   101 = 101, разбивка 48 + 53 = 101.
3. **Четыре числа про четыре периода:** за всё время 134/101, за год 110/83 — **18 новых заказов
   старше 1 января**. Пикер перевозчиков уже говорил 134 над таблицей в 110 строк ДО #841.
4. **`wc_admin_register_page()` HTML в меню пропускает**, но `page_title` обязателен — иначе
   разметка уезжает в серверный `<title>` экранированной.
5. **`sprintf('%d', number_format_i18n(1234))` = `1`** — боевой плагин врёт на 1000+ заказов.
6. **У `.woocommerce-filters-label` ОТЗЫВЧИВЫЙ отступ** (5px до ~1400, 7px выше): контейнер пикера
   78/82 px, кнопка всегда 50 px на нижней грани.

# Ловушки

Только новое за s130; прежнее — по тегам в `GOTCHAS.md`.

1. **Хендофф из рабочего дерева может быть УСТАРЕВШЕЙ копией**, если дерево стоит на ветке,
   отпочкованной до докоммита. Читать с `origin/main` и сверять.
2. **Переиспользованный терминал Orca отдаёт транскрипт ПРОШЛОГО хода** — доехавший бриф читается
   ровно как застрявший в поле ввода. Свидетель — `terminal read --screen`; настоящий сигнал
   застревания это непустой `draft`. Готча заведена.
3. **`--terminal` не совмещается с `--agent`**; переиспользование требует ещё и `--worktree` полным
   селектором `id:<repo-id>::<path>`.
4. **`orca worktree rm` может отрапортовать обрывом связи, УДАЛИВ ворктри.** Проверять
   `git worktree list`, а не код возврата.
5. **Фильтр по `statusCheckRollup`, считающий всё не-`SUCCESS` за падение, читает pending как
   красное.** Честно отвечает `gh run watch --exit-status`.
6. **Вопрос про серверную разметку нельзя задавать DOM'у** — `wc-admin` переписывает
   `document.title` после монтирования. Читать тело ответа. Готча заведена.

⚠ **Читать доску по полю «Приоритет».** Считать с `--limit 300` для issue и **`--limit 1000` для
`project item-list`**: на 300 он молча срезал 22 карточки из 57.
