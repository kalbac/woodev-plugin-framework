# Ловушки

1. **Каст — это не деградация:** `absint('мусор') === 0` останавливает фоновый раннер на первой
   проверке, `(array) 'boom'` даёт список с ключом `0`. Всегда к ДО-фильтровому значению. Готча
   `a-cast-is-not-a-degradation`.
2. **Из `tests/bootstrap.php` нельзя ничего ПЕЧАТАТЬ** — PHPUnit разбирает вывод дочернего процесса
   как результат теста; пять строк `fwrite( STDERR, … )` дали **36 ошибок**. Готча
   `writing-to-stderr-from-the-test-bootstrap-breaks-process-isolated-tests`.
3. **Запрещать воркеру мокать WP/WC-функции надо ОБЩИМ правилом, а не списком имён.** Бриф s102
   запрещал `get_locale` — воркер замокал `WC()` и получил 268 ошибок. Формулировка на будущее:
   «не мокай НИ ОДНУ функцию WP/WC в `setUp()`; если она нужна одному тесту, объявляй её в нём же
   под `@runInSeparateProcess`».
4. **Serena переводит КАЖДЫЙ тронутый файл в CRLF** — чинить сразу после воркера, до коммита: git
   нормализует при `add`, но смешанное дерево ломает поздние правки по переводам строк.
5. **Bash-heredoc съедает уровень экранирования, а на длинном PHP рвётся вовсе** (`unexpected EOF`).
   Python с обратными слэшами — raw-строками или `chr(92)`; длинные файлы класть `Write`.
6. **`worker-start` отвечает `input_accepted`, и это ничего не доказывает** — сверять по
   транскрипту. Воркер s102 умер посреди хода, 24 минуты выглядя `ready`/`live`.
7. **`docker cp` в контейнер рига падает** (`mkdir … file exists`); работает
   `docker exec -i … sh -c 'cat > /tmp/probe.php' < файл`.
