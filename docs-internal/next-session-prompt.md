# Чему научила s51 — читать до правок карты

- **Спека может быть неправа; отменять её надо письменно.** §7.5/«V-10» требовала одинакового
  поведения клика по маркеру и по строке. Оба референса разводят их. План s51 отменил это явно,
  чтобы не «восстановили» обратно. Спека `2026-08-01` §6 к тому же содержит неверную форму
  `margin.addArea()` — реализация честно скопировала неверную спеку.
- **Два референса, и они не взаимозаменяемы.** Для ПОИСКА эталон — Yandex.Delivery
  (`plugins-reference/woocommerce-yandex-delivery/assets/js/frontend/wc-yandex-delivery-widget-map.js`,
  620 строк сырого `ymaps.*`). Бандл Почты — `https://widget.pochta.ru/map/main.a7d147fb5267ec1f0932.js`
  (минифицирован, но имена методов ymaps переживают минификацию — его надо грепать, а не гадать).
  s51 ошиблась, применив модель Почты (без `suggest()`) там, где оператор ждал модель Яндекса.
- **Тесты зелены, а карта сломана — это норма здесь.** jsdom не делает hit-test, ymaps замокан. За
  четыре сессии подряд риг находил то, чего не видел ни один тест. Любое утверждение про поведение
  карты проверять на живом риге, а замеры делать через DOM, а не глазами по скриншоту.
- **Заглушка может согласиться с багом.** В s50 стаб `setFilter()` повторял неверную сигнатуру
  продакшена, и тест подтверждал баг. В s51 просил воркеров явно: сомневаешься в сигнатуре ymaps —
  скажи, а не угадывай. Дважды это спасло (форма `clusters.getById()`, промисы `panTo`/`setCenter` —
  обе догадки оказались верны, но проверил их Codex по документации, а не мы по ощущениям).
- **Как ловить провайдера на риге.** Экземпляр живёт в замыкании. Перед открытием модалки:
  `const P = window.WoodevPickupMapProviders.yandex; const o = P.prototype.init;
  P.prototype.init = function(){ window.__p = this; return o.apply(this, arguments); };`
  затем переоткрыть модалку — дальше доступны `__p.map`, `__p.config`, все методы.
- **Чекаут на риге:** страна RU и регион 77 уже стоят, метод `woodev_test_shipping` выбран, город
  сбрасывается при каждой перезагрузке. Ставить так:
  `sel.innerHTML='<option value="Москва" selected>Москва</option>'; $(sel).val('Москва').trigger('change');
  $(document.body).trigger('update_checkout');` и дождаться `jQuery.active === 0`.
