# С чего начать

Порядок выстроен под АВТОНОМНУЮ ночь: сверху то, что закрывается замером и кодом без единой
развилки, снизу то, где придётся думать за оператора.

1. **#650 — самое чистое на ночь.** `Location_Controller::perform_suggest()` зовёт
   `provider_for_level( $level )` без страны, потому что `$country` читается на 36 строк ниже.
   Провайдер, покрывающий только KZ, отвечает «да» на запрос по RU, и покупатель получает пустой
   список вместо результатов фолбэка. **Что решить самому и запинить тестом:** какой из двух
   400-ответов выигрывает, когда невалидны И провайдер, И страна (перенос чтения страны выше меняет
   порядок валидаций). И отдельный вопрос на карточке: должна ли ветка `provider_by_id()` для явного
   оверрайда тоже учитывать страну — её комментарий сейчас честно пишет «country-blind too».
2. **#647 — механическое, хорошо ложится на воркера.** Переименовать три выброса, где неймспейс не
   отражает каталог (`Shipping\*` → `shipping-method/api|exceptions|settings`), и записать три
   правила в `AGENT-RULES.md` или `DOCS-SCHEMA.md`. Дальше — научить `bin/generate-class-map.php`
   ПАДАТЬ на нарушении конвенции: тогда карта остаётся данными, а конвенция становится гейтом.
   Переезд на конвенционный автозагрузчик **не делать** — замер на карточке.
3. **#646 — маленькое.** Подписи «м»/«км» передать из PHP через `Pickup_Handler::get_js_config()`,
   как все остальные строки карты. Заодно проверить второе, что записано на карточке: мили там
   выбираются по `region === 'US'` из локали, а не по настройке единиц WooCommerce.
4. **Остатки слоя локаций — #356, #358, #361, #410.** ⚠ Не обычные карточки.
   **#361 и #410 РЕШЕНЫ оператором 29.08.2026, решения записаны на сами карточки** — можно
   реализовывать ночью. #361: строку показывать в самом списке подсказок (поверхность одна на
   typeahead и ajax-select2, `related-list` только для региона и вопрос снимает). #410:
   админ-уведомление на страницах Woodev, механизм `Woodev_Admin_Notice_Handler` уже есть —
   но сперва посмотреть **#653**.
   **#358 и #356 ночью НЕ писать.** #358 прямо запрещает «чинить» баном cross-provider scope и
   несёт два ПРОТИВОПОЛОЖНЫХ измеренных исхода; #356 — проектирование forget-пути. По ним
   принести РАЗБОР комментарием на карточку, код — только если разбор покажет, что развилки нет.
5. **#644 — аудит доков и доски.** Открытых карточек **86**, оператор сам нашёл неактуальные.

# Доказано замером

1. **Гейты на `main` (29.08.2026, основной чекаут, sodium включён):** `composer check`
   **3186** / 7826 / **1**; те же числа под `--order-by=reverse`; интеграция **126** / 494;
   jest **1548** / 21.
2. **#567: фронтендовых строк 65, а не 104.** Замер s102 бакетировал по ПУТИ ФАЙЛА; путь рендера —
   свойство МЕТОДА. Плюс правило «первый аргумент — одиночный литерал» пропускает
   КОНКАТЕНИРОВАННЫЙ msgid: таких два, один покупательский.
3. **`strict_types` не объявлен НИГДЕ в `woodev/`.** В `?string`-методе int/float/bool коэрцятся
   молча, array/object дают TypeError, улетающий в `init`. Это решило форму правки в #353.
4. **`get_order()` обязан сохранять конкретный класс заказа** — подкласс `WC_Order` молча
   превращает `WC_Subscription` в обычный заказ. Вариант отвергнут по замеру.
5. **`provider_for_level()` страно-слепой НАМЕРЕННО** — `$country` добавлен позже. Дефект был в
   вызывающих: из семи слепых три, из них `get_supported_countries()` корректна по построению.

# Ловушки

1. **Зелёный тест, проходящий и БЕЗ правки, не доказывает ничего.** В s103 так вышло дважды.
   Мутировать код и убедиться, что тест КРАСНЕЕТ, — обязательный шаг. Готча
   `measure-a-gate-where-the-gate-can-actually-fire`.
2. **Codex: `--model` НЕ передавать** (см. шапку). Признак живого хода — статусная строка
   `Working (Ns • esc to interrupt)`, а НЕ отсутствие ошибки в хвосте: фатальная печатается
   последней, за шумом MCP. Бриф приезжает НЕОТПРАВЛЕННЫМ — нужен
   `terminal send --text "" --enter`. Канарейка первой строкой брифа обязательна.
3. **После смерти воркера `worker-stop` отвечает `stop_unknown`**, и задача не возвращается в
   `ready`, пока мёртвый диспатч активен. Не воевать — завести НОВУЮ задачу с тем же брифом.
4. **Старт воркера проверять ПО ТРАНСКРИПТУ**, не по `input_accepted`.
5. **Serena переводит КАЖДЫЙ тронутый файл в CRLF** — чинить сразу после воркера, до коммита.
6. **Bash-heredoc съедает уровень экранирования**; Python с обратными слэшами — через `chr(92)`.
7. **Потолок 2-3 агента — ФИЗИКА машины.** И: пока критик рецензирует НЕЗАКОММИЧЕННЫЙ диф в
   рабочем дереве, второго воркера туда пускать нельзя — он испортит предмет обзора.
