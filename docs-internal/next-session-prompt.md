# Ловушки — самое дорогое из s90

1. **Закешированный ассет под неизменившимся `?ver=` читается как неработающая фича.** Два прохода
   подряд выглядели как «клиент игнорирует ответ сервера». Hard-reload не помог; свежий изолированный
   контекст не помог; `fetch()` того же URL из страницы ВРАЛ, отдавая новый код из того же кеша.
   **На риге держи DevTools открытыми с «Disable cache».** Готча
   `a-cached-asset-under-an-unchanged-ver-reads-as-a-broken-feature`.
2. **`disabled` выбивает поле из `form.checkout.serialize()`**, а `readonly` на `<select>` не делает
   ничего (свойства нет). Собственный `select2('enable', false)` реализован поверх нативного
   `disabled` и платит ту же цену. Готча
   `disabled-drops-a-checkout-field-from-the-form-readonly-is-inert-on-select`.
3. **`agent_prompt_stalled`: Enter спасает работу, но НЕ диспетч.** Capability отзывается через ~30
   секунд, поэтому `worker_done` приходит завёрнутым в отказ. Результат читать из ветки, задачу
   закрывать руками. Дополнено в готче `dispatch-inject-reports-failure-after-succeeding`.
4. **`rm -f .phpunit.result.cache` перед каждым замером. JS-тесты из bash. Сравнивать skipped = 66.**
   В ворктри критика их 1 — это известная инверсия, а не дефект.
5. **Диалог обновления Codex — ESC, не Enter.** Enter означает «Update now».
