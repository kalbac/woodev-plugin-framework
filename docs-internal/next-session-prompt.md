# Что доказано замером

1. **Сырой размер payload — НЕ цена на проводе.** +47,0 КБ сырых у локали стран = **+503 байта
   после gzip** (≈96:1). На этом **#364** закрыта как «не планируется» — условие назвала сама
   карточка. Посылка проверена: `/checkout/` отдаётся `Content-Encoding: gzip` на голом Apache из
   `wp-env`. Готча `a-raw-payload-size-is-not-a-wire-cost-measure-it-after-gzip`.
2. **Висячий `require_once` НИКОГДА не был невидим; а «класс в карте, но не требуется» не ловит
   НИЧТО, кроме одного теста.** Удалённый файл валит обе сюиты; класс, выпавший из `includes()`,
   оставляет интеграцию **зелёной** — автозагрузчик берёт его из `class-map.php`. Так список и
   сгнил до 31 файла. ADR-012 утверждал обратное и исправлен. **Новый класс под
   `woodev/shipping-method/**` дописывать в `includes()`.**
3. **`.mo` собирается ТОЛЬКО `wp i18n make-mo`** — рукописный компилятор дал рабочий, но ДРУГОЙ
   файл (61 421 против 61 491 байта), ломая готчу `the-mo-is-reproducible-from-the-po`.
4. **Ворктри Orca видны внутри контейнеров рига** (`wp i18n make-mo` по `.po` воркера работает), но
   **интеграцию оттуда гонять нельзя**: phpunit стартует и умирает на фикстурах, потому что
   `WOODEV_FRAMEWORK_DIR` смотрит в основной чекаут. Гонять detached-чекаутом в основном дереве.

# Ловушки

1. **`orchestration send` — ПОЧТА, а не инъекция в промпт.** Возвращает `ok: true`, но воркер
   прочитает её, только если сам позовёт `orchestration check`. В s118 два воркера Sonnet не позвали
   ни разу за 28 минут, и один построил ровно то, что запрещала непрочитанная поправка. **Требовать
   `orchestration check` явным пунктом брифа**, а срочное слать `terminal send`. Готча
   `orchestration-mail-is-not-read-unless-the-worker-calls-check`.
2. **Сверять бриф с `GOTCHAS.md` ДО отправки воркеру.** Обе поправки s118 были не нужны: и про
   `wp i18n make-mo`, и про матрицу сюит уже лежало в докáх. Починка круга дороже правильного брифа.
3. **`plugins-reference/` в `.gitignore`** — читающий оттуда тест зелен локально и в ворктри, красен
   в CI. Готча `a-test-reading-a-gitignored-directory-is-green-locally-and-red-in-ci`.
4. **`cd` в Bash-инструменте СОХРАНЯЕТСЯ между вызовами** (переменные — нет): позднейший
   `git checkout -b` уходит в посещённый ворктри. Только `git -C` и абсолютные пути. Готча
   `a-cd-in-the-bash-tool-persists-and-sends-the-next-git-command-into-a-worktree`.
5. **Инлайн в bash съедает слеши и бэктики — включая ПРОВЕРКУ, которой ты это ловишь**, а Serena
   `replace_symbol_body` переводит ВЕСЬ файл в CRLF. Только файлом, мерить байтами. Готча
   `serena-replace-content-eol-flip`. ⚠ И `python -c` с кириллицей в ВЫВОДЕ падает на `cp1251` —
   писать в файл с `encoding='utf-8'`.
6. **Codex под Orca:** четыре шага из `starting-codex-under-orca-needs-four-steps-not-one`.
   ⚠ Модель — **`gpt-5.6-terra`**; `gpt-5.3-codex` даёт HTTP 400. ⚠ Требование «бандл с канарейкой»
   в `CLAUDE.md` УСТАРЕЛО — **#773**.
7. ⚠ **`worker-release` отвечает `ok: true` и может ОСТАВИТЬ агента жить.** Читать `state`, не `ok`,
   и в конце пройтись `orca terminal list` / `worker-list` / `task-list`. Готча
   `worker-release-answers-retained-and-leaves-the-terminal-running`.
8. **Оба док-гейта ТЕСНЫЕ:** `CURRENT-STATE.md` 28,4 из 28 КБ-гейта, этот файл — у своих 16 КБ.
   Любое добавление ДОЛЖНО что-то вытеснить; в s118 пришлось сжимать четыре блока рига.
