# Известные ограничения проверки, оставленные s80

- **JS-логика `hide_for_pickup`/`chosenIsPickup()` (задача 9) не проверена вживую на реальном
  срабатывании** — единственный активный метод на риге (`Woodev Test Shipping`) имеет
  `delivery_type='courier'`, а не `pickup`, поэтому `pickup_method_ids` на риге пуст. Покрыто
  только 8 jest-тестами. **Задача 12's риг-матрица явно требует этот путь** (пункт 4: скрытие
  индекса для pickup-метода) — либо активировать `woodev-yandex-pilot-plugin` фикстуру
  (единственная в репо с реальным `TYPE_PICKUP` через `Shipping_Method_Pickup`), либо найти
  другой способ. Разберись перед тем, как писать в отчёте «проверено».
- Локаль страны на блочном чекауте выросла с 10 КБ до 58 КБ (250 стран магазина на риге) —
  замерено, задокументировано, карточка `#364` в `Бэклог`. Не блокер, но держи в уме при
  финальной риг-матрице (задача 12) — если операторская проверка на реальном магазине покажет
  иную картину (меньше стран), это ожидаемо.

# ⚠️ Ловушки, всё ещё в силе

   тестах сажать страну явно.

   подметает чужое — перечислять файлы явно (s80 сам наступил на смежную версию этой ловушки:
   недокоммиченные правки на `main` тащились при переключении веток — стешить перед `checkout`).
5. `Woodev_Setting::get_value()` кэширует — `update_option` посреди запроса не виден. Актуально
   для `address_suggestions` (задача 10): тест должен строить хендлер ПОСЛЕ подмены `get_option`.
