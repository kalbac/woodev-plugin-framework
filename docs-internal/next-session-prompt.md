# Доказано замером

1. **Гейты на `main` (`78ead18`, 27.08.2026):** `composer check` **2966** / 7139 / **66 skipped**;
   jest **1545** в 21 сьюте. Мерено в ворктри — доверять можно ТОЛЬКО потому, что skipped вернулся
   66, как в основном чекауте. **Интеграция на `main` НЕ измерена** (контейнер был занят веткой
   #518); на той ветке было 126 / 494. Перемерить.
2. **#518 достижим ровно в одной конфигурации** — `dadata` + `geoip`. При `fixed` запись после
   #536 не считается неявной; `geoip` предлагает только провайдер с capability `locate`, а такой
   один. Таблица на карточке.
3. **`geoip` на локальном риге не разрешает НИЧЕГО** — IP покупателя `127.0.0.1`. Выглядит как
   сломанная фича. Готча `the-geoip-default-locality-cannot-resolve-on-a-local-rig`.
4. **Мой замер спреда `response_message` был НЕПОЛОН** — грепал только `woodev/**` и пропустил
   `plugins-reference/`. Там настоящий поведенческий читатель, ветвящийся по префиксу
   `unauthorized`. Утверждение стояло в докблоке КАК ФАКТ. Правило: **грепать и донорские
   плагины**, `.worktreeinclude` их копирует.
5. **Замок адреса не ограничен методами «до ПВЗ»** — `isAddressLocked()` про метод доставки не
   знает вовсе. Значит при КУРЬЕРСКОМ методе с `geoip` поле заперто, а снять замок выбором пункта
   невозможно — пунктов нет; выход только через явный выбор НП. И поле НП при этом может выглядеть
   заполненным (значение из сессии WooCommerce, не из нашей записи), так что видимого запроса
   «выберите НП» покупатель не получает — замок вырождается в немую блокировку. Замечание
   оператора при приёмке #518.

# Ловушки

1. **`phpunit a.php b.php` гоняет только `a.php`.** Остальные молча отброшены. Один мой
   ФАЛЬСИФИКАЦИОННЫЙ прогон покрыл треть заявленного и выглядел успешно. Всегда `--testsuite=Unit`,
   один путь за раз, и сверять `Tests: N` с тем, сколько тестов в файлах. Готча
   `phpunit-takes-one-path-and-silently-ignores-the-rest`.
2. **Замер сразу после сброса состояния рига врёт.** Цепочка досевается не мгновенно: пока в ней
   только `settlement` без `region`, `scopeKeyFor(entry,'address')` возвращает `null` и адрес
   заперт по ПЕРВОЙ половине условия. Я принял это за регрессию собственной правки; контроль на
   `78ead18` показал, что нет. **Контроль обязателен, одного чтения мало.**
3. **`LocationServiceDefaultTest` не гоняется в изоляции** — падает 27/28 и без правок. Мерить
   полным прогоном. Причина не диагностирована.
4. **`docker cp` в контейнер рига падает** на конфликте симлинка. Заливать через
   `docker exec -i sh -c 'cat > /tmp/…'`.
5. **Serena игнорирует `tests/_fixtures/`** (`path is ignored`) — для фикстур обычные инструменты.
6. **Локальный PHP 8.5, пол CI — 7.4.** Зелёный `composer check` здесь — свидетельство про 8.5.
7. **`git checkout -- <file>` выбрасывает несохранённую работу.** При фальсификации —
   `git stash push -- <file>` плюс `git stash pop`.
8. **`composer check` и jest — не одно дерево.** `rm -f .phpunit.result.cache` перед каждым
   замером; jest только из bash с `--roots`, никогда `npx jest`.
9. **Serena пишет CRLF.** Питоновский поиск по `\n` не совпадёт — искать по `\r\n`.
