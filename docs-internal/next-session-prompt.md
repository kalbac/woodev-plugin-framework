# Что доказано замером

Полностью — в `sessions/s124.md`. Пять фактов, нужных сразу:

1. **Четыре порядка объявления фичи** метода доставки (зонд на риге, WC 11.1.0). До s124 работал
   один из четырёх; документированный — `add_support()` после конструктора — давал флаг без
   контрола. После — работают все четыре.
2. **156 → 163 теста, ни один существующий не потревожен** — радиус монтирования фикстуры (#814).
3. **Риг после `npx wp-env start` — байт в байт**; префикс контейнеров не изменился.
4. **Один круг Codex `gpt-5.6-terra` `high` = недельный лимит с < 25 % до < 10 %.** Читать из
   `token_count` в роллауте под HOME Orca, НЕ из `orca account list` (кэш). На 07.09 06:58 UTC:
   5-часовое окно 17 %, недельное **90 %**, сброс недели 17:02 UTC того же дня.
5. **Отказ перевозчика — не исключение** (брейншторм #114). `handle_response()` кидает только на
   `is_wp_error()`; границу проводит каждый плагин сам в `do_post_parse_response_validation()`,
   которая во фреймворке — пустая заглушка `{}`, а реализуют её ВСЕ шесть боевых плагинов.

# Ловушки

Только новое за s124; прежнее — по тегам в `GOTCHAS.md`.

1. **Незамапленная фикстура кладёт ВСЮ интеграционную сьюту**, а не свои тесты, и сообщение про
   `class-plugin.php` читается как сломанный `vendor`. Готча `wpenv-resolver-fixture-mapping`.
2. **Зелёная сьюта — не доказательство отсутствия загрязнения.** Зондовые подклассы оставляли в
   синглтоне записи без `class_name`; сьюта была зелёной, потому что туда никто не ходит.
   **Перед «заведу свою фикстуру» перебрать существующие.**
3. **Сеттер, пересчитывающий производное состояние, не должен делать это ВНУТРИ пересчёта.** Готча
   `a-base-constructor-that-assigns-what-the-subclass-just-set`.
4. **Квотированный heredoc через Bash-инструмент съедает обратные слэши** — Python падает
   синтаксической ошибкой. Скрипты писать инструментом Write. Готча
   `the-bash-tools-quoted-heredoc-still-eats-backslashes` (подтверждена в s124).
