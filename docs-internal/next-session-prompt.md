# Что доказано замером

1. **Фреймворк разделяет источники ПВЗ по ПЛАГИНУ, а не по методу, и всегда разделял.**
   `class-pickup-controller.php:314` — «so that each shipping plugin registers a DISTINCT route»;
   `Point_Source` — приватный аргумент конструктора одного `Pickup_Handler` на плагин. Дырки в
   продукте нет; ограничение было риговым.
2. **Выбрать источник по выбранному методу нельзя:** `error_log` внутри самой функции дал
   `rest=no wc=ok session=none` — хендлер строится ДО сессии WooCommerce, а REST за точками в эту
   ветку не заходит.
3. **Сверка #709 ложно срабатывает на мультиплагинном магазине** — сравнивает флот с одним
   хендлером через равенство множеств. Карточка #736.
4. **Фикстура, которую гонял только PHPUnit, на первой живой загрузке WP даёт три отказа подряд** —
   не регистрирует себя, фаталит `load_updater()` на заглушенной лицензии, делит id поля чекаута со
   вторым перевозчиком. Все три невидимы зелёной сьюте. Готча
   `standing-up-a-second-carrier-plugin-has-three-traps-a-green-unit-suite-cannot-see`.
5. **`Pickup_Point::from_array()` возвращает `null` МОЛЧА** при `lon` вместо `lng` или скалярном
   `type` — сломанная фикстура отдаёт пустой список без единой ошибки. Поэтому тест на точки обязан
   их СЧИТАТЬ, а не просто дёргать источник.

# Ловушки

1. **Часть состояния рига git НЕ отслеживает, и в s112 её прибавилось.** Кроме двух ПВЗ-констант
   (`WOODEV_TEST_PICKUP_LIVE_YANDEX=true`, `WOODEV_TEST_PICKUP_STRATEGY=viewport`) теперь есть:
   активированный плагин `woodev-realistic-shipping-plugin`, его метод в зоне 1 как instance **5** и
   применённый `npx wp-env start` под новый маппинг. Если ПВЗ поведёт себя странно — сверять это
   первым делом.
2. **Тело PR закрывает карточки ЧЕРЕЗ ОТРИЦАНИЕ, и предупреждения в брифе НЕ ХВАТАЕТ.** Сработало
   второй раз подряд. Писать не запрет, а шаблон `Refs #N — <что осталось>`, и **проверять после
   каждого мержа**: `gh issue view N --json state`.
3. **`gh project item-add` может вернуть код 0 и не добавить элемент.** В s112 карточка #737 попала
   на доску только со второй попытки; проверять `item-list` после добавления.
4. **Serena игнорирует не только `tests/`**: `tests/** docs/** .github/** .ai/** .serena/** .claude/**`.
   Правило с исключением теперь в `AGENT-RULES.md` и `CLAUDE.md`.
5. **Ворктри стартуют грязными с СЕМЬЮ CRLF-файлами**; `git checkout --` их не чистит, Orca без
   `--force` удалять отказывается.
6. **Гейты размера сработают:** `CURRENT-STATE.md` в s112 пробивал потолок дважды. Вытеснять надо
   ИСТОРИЮ, а не живой факт.
