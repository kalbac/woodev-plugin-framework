# ⚠️ Ловушки, купленные дорого

1. **Зелёный сьют говорит о фиче ровно столько, сколько его тесты реально исполняют.** Арбитраж
   #294 был мёртв в конфигурации ПО УМОЛЧАНИЮ при 2012 зелёных тестах: `WC_Countries::get_states()`
   отдаёт `false`, а не `[]`, и `(array) false` непуст. Ни один тест не исполнял тело метода —
   все подменяли шов `wc_states()` фикстурой. **Шов, добавленный ради тестируемости вызова WC,
   заодно даёт сьюту возможность никогда его не запускать: к каждому такому шву нужен ОДИН тест
   на реальное тело.** Готча `array-cast-of-get-states-false-is-not-empty`.
2. **Замер может отменить решение, принятое по предыдущему замеру.** Опаковый ключ в `billing_state`
   плох (остаётся в заказе навсегда и печатается сырым без плагина), но и человеческая подпись
   плоха: WooCommerce поднимает регистр и переставляет карту `ПОДПИСЬ → КЛЮЧ`, из-за чего регион
   молча пропадает при следующем рендере. Верна третья форма: ключ `wc_strtoupper(trim(подпись))`,
   значение — подпись. Готча `wc-uppercases-the-posted-state-and-flips-the-map`.
3. **Критик может не отработать вовсе, и это надо проверять.** Codex трижды не смог: песочница
   Windows отказывает в создании процессов, он честно вернул «проверить не могу». А субагент-критик
   один раз вернулся, вообще не запустив ревью («подожду уведомления»). Проверяй факт прогона, а не
   наличие ответа. `node ~/.claude/plugins/cache/openai-codex/codex/1.0.4/scripts/codex-companion.mjs status`.
4. **Контрольная проба превращает «стало зелено» в утверждение.** #293 проверен так: враждебные
   константы намеренно ВЕРНУЛИ в tests-контейнер, `main` дал 4 падения + 1 ошибку, ветка — 104
   теста зелено. Без контроля обе половины правки выглядели бы одинаково.
5. **`.wp-env.override.json` — зеркало, а не источник.** Авторитет риг-констант — `wp config set`
   внутри контейнера; разнесение файла по секциям `env.development` само по себе не меняет ничего.
6. **`git add -A` в свежем рабочем дереве** подметает нормализацию CRLF→LF файлов, которых не
   открывал: в коммит на две строки уехали четыре чужих JS-ассета, включая платёжный. Стейджить
   явно, перед пушем — `git show --stat --format="" HEAD`.
7. **`npm run test:js -- --roots "<rootDir>/tests/js"` из PowerShell не работает** — токен
   `<rootDir>` не разрешается, jest говорит «No tests found», и это читается как сломанный сьют.
   Запускать из bash.
8. **Поднятие `VERSION` на `main` публикует релиз** — джоб `release` сам создаёт тег, коммитит
   CHANGELOG и выкладывает GitHub Release с ZIP. Делать сознательно, перед релизом (#285).
9. Готчи в силе: `rig-serves-the-working-tree-branch-switch-reverts-fixes`,
   `checkout-field-takeover-woocommerce-states`, `jquery-trigger-change-fires-no-native-event`,
   `jest-resetmodules-leaves-listeners-on-the-surviving-body`,
   `woodev-setting-get-value-is-cached-not-a-live-option-read`.

# Как оператор работает — что подтвердилось в s71

Он отвечает на развилки пачкой и уходит, отдавая всё остальное на автономию. Формулировать вопросы
надо так, чтобы ответы закрывали ночь целиком: в s71 четыре ответа (мержить ли #279, какой вариант
размещения кнопки, что делать с версией, что показывать при чужом городе) сняли все блокировки до
утра. Архитектурные развилки он сознательно отдаёт агенту — но «реши сам» означает **замер**, а не
свободу выбора: в этой сессии два решения подряд были приняты замером и одно из них следующим
замером отменено.
