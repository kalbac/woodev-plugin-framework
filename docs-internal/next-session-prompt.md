# Ловушки — самое дорогое из s88

1. **Замеряй ЭКРАН, а не payload.** Сервер отдавал по REST два пункта, админка рисовала три —
   у #404 была клиентская половина в `control-field.js`. Три серверных замера подряд были верны и
   бесполезны. Готча `narrowing-a-server-option-list-has-a-client-half`.
2. **Контроль, который проходит, — не контроль.** Тест на #486 трижды проходил против заведомо
   сломанной реализации: закрытый кастомный селект не держит опций в DOM; контрольный патч правил
   не ту ветку; потом ту, но с меткой-заглушкой. Готча `a-closed-custom-select-renders-no-options`.
3. **Falsy в карте владения — это ОТКРЫТЫЕ ворота.** Пустой `owners[c][level]` не «владельца нет»,
   а «проверку не делать»: `backwardsFill()` защищён через `if ( owner && ... )`. Готча
   `an-empty-level-owner-silently-disarms-the-cross-provider-guard`.
4. **Зелёный сьют молчал про дефект, блокирующий оформление заказа.** `refreshAddressLock()` ходит
   только по ТЕКУЩЕМУ узлу цепочки — оставленное поле навсегда оставалось `disabled`. Нашлось
   только проходом в браузере. Самопроверка на риге до просьбы к оператору — обязательна.
5. **Ветку PR резать от `main`, а не от другой ветки PR.** Один раз за сессию поймал стек, до PR.
   Готча `stacked-pr-github-mechanics`.
6. **Serena переворачивает EOL всего файла** при `replace_symbol_body` — проверять
   `git diff --stat` сразу. Готча `serena-replace-content-eol-flip`.
7. **`rm -f .phpunit.result.cache` перед каждым замером. JS-тесты из bash. Бандлы — только в
   основной копии** (после правки `src/` обязательно `npm run build`, CI это проверяет).
8. **Диалог обновления Codex** всплывает при каждом запуске, Enter там значит «Update now». ESC.

# Как здесь принято работать — что подтвердилось в s88

- **Замерить, а не читать.** Замер фан-аута вскрыл #481 до того, как оператор потратил бы на это
  риг-проход. Замер `owners` дал причину #484 за один проход.
- **Тесты умеют возражать плану — слушать их.** Широкая версия фикса #484 правила ещё и
  `levels['region']`; её завалил существующий тест, который пинит `false` намеренно. Он был прав.
- **Вердикт критика тоже проверяется.** Codex дал два HIGH: один настоящий дефект, второй — то же,
  что я нашёл замером. Фоновое ревью пуша дало ложную тревогу, но рядом с ней — настоящую придирку.
- **Развилки поднимать к оператору, а не решать молча.** #481 и режим НП оба ушли к нему и оба
  вернулись решением за минуту.
