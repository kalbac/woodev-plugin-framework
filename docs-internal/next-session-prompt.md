# Что доказано замером

Полностью — в `sessions/s128.md`. Пять фактов, нужных сразу:

0. **`addHistoryListener` шлёт событие ДО смены адреса**, поэтому `getQuery()` внутри слушателя
   читает ПРЕДЫДУЩИЙ URL и страница отстаёт на навигацию: адрес меняется, таблица нет. Готча
   `addhistorylistener-fires-before-the-url-changes`. **Найдено только живым ригом.**
1. **Опция фильтра у WooCommerce — `{ value, label }`, не `{ key, label }`.** Ошибка формы делает
   кнопку «Filter» **disabled**, а выбранный пункт отправляет ЛЕЙБЛ вместо ключа. Готча
   `a-filter-option-keyed-key-instead-of-value-disables-the-filter-button`.
2. **WooCommerce ХАРДКОДИТ имя параметра `filter`.** `FilterPicker` на этом параметре ОБЯЗАН
   получить проп `advancedFilters`, иначе выход из расширенного режима кидает `TypeError`
   (`filter-picker/index.js:174`, у пропа нет defaultProp). Нашёл критик, подтверждено исходником.
3. **«Совпадать ни с чем» — ровно ОДИН верный механизм.** Пустой массив статусов HPOS разворачивает
   во ВСЕ валидные; выдуманный слаг пустой на HPOS и БЕЗДЕЙСТВЕН на legacy-CPT. Использовать
   `Orders_Query::NO_MATCH_META_QUERY`.
4. **Агрегат с ОДНИМ источником — не малое N, а другая форма**; скрыл два дефекта подряд (s127
   `has_tracking`, s128 `delivery_status=unknown`). Тест на агрегат — минимум два перевозчика.
5. **Замеры на риге (HPOS, 2 перевозчика, 71 заказ):** `delivery_status=unknown` 71 → **9** (106 мс),
   `status=["nonsense"]` 71 → **0**, `status=["Pending payment"]` 71 → **0**; контроли
   `in_transit` 19 и `has_tracking=false` 24 не менялись.

# Ловушки

Только новое за s128; прежнее — по тегам в `GOTCHAS.md`.

1. **Убитый PHP-процесс НЕ убивает запрос в MySQL** — следующий прогон виснет на `DROP TABLE
   wp_users`. `SHOW FULL PROCESSLIST` первым делом; клиент называется `mariadb`. Готча
   `killing-phpunit-leaves-its-mysql-query-running-and-holding-locks`.
2. **Инлайновая проверка EOL врёт в обе стороны** — `grep -c $'\r'` дал 0 на CRLF-файле, `sed | od`
   показал LF на CRLF-каталоге. Авторитет: `file`, предупреждение git, чтение байтов одним
   процессом. Дописано в готчу `perl-multiline-mutation-silently-misses-crlf-files`.
3. **Codex может упереться в жёсткий лимит аккаунта** («try again at 1:49 AM»); предложенное им
   переключение на luna лимит не снимает. Критиком тогда Fable 5.1 — сработал, нашёл блокер.
4. **`worker-start --terminal` требует и `--worktree`** — иначе `terminal_worktree_mismatch`.
5. **Пробы на риг — Playwright с логином `admin`/`password`**, конфиг в scratchpad, НЕ в
   репозитории. ⚠ Запускать с `NODE_PATH=D:/Projects/woodev_framework/node_modules`, иначе конфиг
   вне репозитория не резолвит `@playwright/test`. ⚠ И `page.screenshot({path})` пишет относительно
   CWD — то есть В КОРЕНЬ РЕПОЗИТОРИЯ; давать абсолютный путь.
6. **Оператора для логина на риг звать НЕ НУЖНО** — это делает зонд. В s128 я попросил его зря.
