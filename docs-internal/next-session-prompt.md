# Ловушки

1. **Локальный PHP 8.5, пол CI — 7.4.** `ReflectionProperty::setValue()` на приватном свойстве
   требует `setAccessible( true )` ниже 8.1 и ругается deprecation с 8.5. Зелёный
   `composer check` здесь — свидетельство про 8.5 и ни про что больше. Готча
   `the-local-php-is-four-versions-above-the-ci-floor`.
2. **`git checkout -- <file>` выбрасывает несохранённую работу.** При фальсификации пользуйся
   `git stash push -- <file>` плюс `git stash pop`; `checkout` во время такого прохода стоил мне
   переделки всех правок в одном файле.
3. **Сырые управляющие байты, записанные экранированием, перекодируются.** Байт CSI доехал до
   файла как валидный UTF-8 `c2 9b`, и каждый кейс молча перестал проверять свою ветку.
   Строить через `chr( 0x9b )`. И `preg_match` с флагом `u` возвращает **FALSE, не 0**, на
   невалидном UTF-8.
4. **`parse_str()` теряет информацию** — строит массивы, нормализует ключи (точка и пробел в
   подчёркивание). Сравнивать две query-строки через него нельзя: любая потеря РАСШИРЯЕТ
   совпадение.
5. **Тест, который сам себе готовит предусловие, не проверяет производителя.** Удали скрытый
   input из вьюхи — четыре теста гварда останутся зелёными, а редактирование токенов в админке
   молча перестанет сохраняться.
6. **Проверять отдаваемое ригом надо В КОНТЕЙНЕРЕ, а не на диске.**
7. **`composer check` и jest — не одно дерево.** `rm -f .phpunit.result.cache` перед каждым
   замером; jest только из bash с `--roots`, никогда `npx jest`.
