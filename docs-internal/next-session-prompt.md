# Что доказано замером

1. **`lint:i18n` отвечает про КАТАЛОГ, а не про код.** Читает только `…ru_RU.po` и ходит по его
   записям; исходники не сканирует. Новая английская строка, не доехавшая до `.pot`/`.po`, проходит
   гейт зелёной — замерено на живом примере в PR #787. Карточка **#791**.
2. **Деньги нельзя сравнивать сырым вычитанием.** `10.00 - 9.99` = `0.00999999999999978`, поэтому
   `0.01 > остаток` истинно и последняя копейка не списывается. Круглые числа (100/60/40) этого не
   показывают — там арифметика точна.
3. **`detach()` рендерера чекаута не отменяет ничего**, а `enqueueSelect()` —
   «последний-записавший-выигрывает» и от протухшего вызывающего защититься не может. ⚠ Токен
   занятости — НЕВЕРНЫЙ ключ к «меня перебили»: `settleSelect()` гасит его безусловно. Обе половины
   с тестами — в готче `a-detach-that-only-unbinds-…`.
4. **Повторяющегося id поля у мастера в дереве НЕТ** — единственная реализация `register_steps()`
   даёт один настроечный шаг; подтверждено и на риге. #783 — упрочнение, не живой баг.
5. **`SESSION-LOG.md` — 47 262 байта, запас ~1,9 КБ.** Ломает его ДЛИНА строк, а не число сессий.
