**Три вещи, о которых план предупреждает особо:**

  Поэтому порядок/скрытие/обязательность — через `woocommerce_get_country_locale` (оба чекаута),

- **Удаление двух аргументов конструктора `Pickup_Handler`** (`$replace_address`, `$close_on_select`)

- **Инварианты поля НП восстанавливаем поверх ИТОГОВОГО массива** (поздний приоритет), с заметкой

  являются дефолтными WC».

# ⚠️ Ловушки, всё ещё в силе

1. Мутация тестов через `perl` молча не применяется в CRLF-дереве — мутировать через `Edit` и
   `grep`-ом убеждаться, что мутация в файле (`perl-multiline-mutation-silently-misses-crlf-files`).
2. Мерить гейт там, где он может сработать: `BY`/`KZ`/`UZ` обслуживают адрес, `AM`/`AZ`/`KG`/`TJ`/`TM` — нет
   (`measure-a-gate-where-the-gate-can-actually-fire`).
3. `ReflectionProperty::setValue()` на приватном свойстве — guard `setAccessible()` по версии PHP
   (`reflection-setaccessible-version-guard`), CI гоняет 7.4/8.0/8.1.
4. WooCommerce определяет страну свежего гостя ГЕОЛОКАЦИЕЙ с фолбэком `US` — в интеграционных
   тестах сажать страну явно (`wc-customer-default-location-geolocation-fallback`).
5. `rig-serves-the-working-tree-branch-switch-reverts-fixes`; JS-тесты ИЗ BASH
   (`powershell-drops-the-roots-flag-from-the-jest-command`); `git add -A` подметает чужое —
   перечислять файлы; поднятие `VERSION` на `main` публикует релиз (#285).
6. `Woodev_Setting::get_value()` кэширует — `update_option` посреди запроса не виден
   (`woodev-setting-get-value-is-cached-not-a-live-option-read`); важно для тестов задач 5/8.
