# ⚠️ Ловушки, купленные дорого

1. **Зелёные сьюты по обе стороны шва ничего не говорят о шве.** Сервер перешёл на карту `levels` по
   странам, клиент читал плоскую — не прицепился бы ни один виджет, при 1957 unit и 963 jest
   зелёных, потому что каждая сторона строит свои фикстуры сама. Меняешь форму конфига — проверяй
   потребителя руками или в браузере.
2. **Риг отдаёт РАБОЧЕЕ ДЕРЕВО.** Две активные ветки при одном дереве, которое и есть риг, — источник
   ошибки: дважды позвал оператора смотреть не то. Сводить в одну ветку ДО того, как звать.
3. **Контрольная проба обязательна.** Первый заход враждебной темы «нашёл» четыре дефекта, которые
   все оказались одним закрытым списком.
4. **`woocommerce_checkout_get_value` — фильтр КОРОТКОГО ЗАМЫКАНИЯ**, а не пост-обработки: WC зовёт
   его с `null` ДО резолва и берёт ответ, только если он не `null`.
5. **Мок `WC` через Brain Monkey определяет функцию глобально** и ломает чужие тесты, ожидающие её
   отсутствия — использовать шов (`wc_customer()`, `wc_country_codes()`), а не глобальный мок.
6. Готчи в силе: `reflection-setaccessible-version-guard`,
   `a-no-leak-test-needs-a-low-entropy-placeholder`,
   `flat-where-isolation-loses-to-a-longer-theme-selector` (новая),
   `jquery-trigger-change-fires-no-native-event`,
   `a-programmatic-parent-change-must-not-run-a-destructive-cascade`.
