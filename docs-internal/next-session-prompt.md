# Что доказано замером

Подробности — `sessions/s133.md`.

1. **Пустая строка в мете СОЗДАЁТ строку, и `EXISTS` её ловит** — риг, HPOS, заказ-зонд 171. Вместе
   с тем, что `export()` пишет мету безусловно, а `Orders_Query` спрашивает присутствие, а не
   значение, — это и есть **#860**.
2. **Обратного перехода нет** (`cancel()` мету не удаляет) и **массовой выгрузки нет** (у `export()`
   ровно один вызывающий).
3. **Полное правило `.order-status`** (по `getComputedStyle()`, не по грепу): плюс
   `white-space: nowrap`, отступ на внутреннем `<span>` (`margin: 0 13px`), `margin: -0.25em 0`.
4. **Таблица на 390px НЕ схлопывается в карточки** — шесть колонок и горизонтальная прокрутка;
   **тултип на тач недостижим ни одним путём** (Ariakit *purposely ignores mobile touch*).
5. **Обе сеялки не зовут `set_billing_*` и `add_product()`** — отсюда пустые «Покупатель», адрес и
   нулевая «Оплата».

# Ловушки

Только новое за s133; прежнее — по тегам в `GOTCHAS.md`.

1. **Греп по чужому стилю — НЕПОЛНЫЙ замер** (готча). Мерить `getComputedStyle()` по живому
   элементу вендора, и смотреть на ДОЧЕРНИЕ элементы тоже — отступы часто живут там.
2. **«Сборка зелёная» у воркера ≠ «бандлы закоммичены».** Показал это только отказ
   `orca worktree rm` удалять грязное ворктри — он печатает незакоммиченное. Гонять его БЕЗ
   `--force` первым, как аудит.
3. **Числа гейтов из ворктри врут:** у #858 было 3822 теста при 67 пропущенных и МЕНЬШЕМ числе
   ассершенов, чем в основном дереве при 1 пропущенном.
4. **jsdom не считает раскладку** — перенос, вылезший бейдж, съехавшая колонка не видны никакому
   jest. Открывать страницу.
5. **Зонды Playwright пишут в `.playwright-mcp/` В КОРНЕ РЕПОЗИТОРИЯ, и он НЕ в `.gitignore`.**
   Выносить в скретчпад и подчищать; MCP наружу репозитория писать отказывается.
