# Что доказано замером

1. **Риг НЕ гоняет фикстурный источник ПВЗ.** `WOODEV_TEST_PICKUP_LIVE_YANDEX = true` в
   `wp-config.php` контейнера, и этот флаг **выигрывает у всего** — раньше почтового и раньше
   `WOODEV_TEST_PICKUP_STRATEGY` (`viewport`). Модалка отдаёт **300 реальных точек Яндекс Маркета по
   Москве**. Следствие: работа #270 корректна и покрыта тестами, но **на риге не выполняется**, а
   #150 недостижима. Готча `the-rig-runs-the-live-yandex-point-source-so-a-fixture-change-may-never-reach-it`.
2. **Фикстура (при прямом вызове) знает три города:** Москва 52, Санкт-Петербург 4, **Краснодар
   ровно 1**, Урюпинск 0. Одна точка в городе — это форма, которую ждёт #150.
3. **Провайдер `test-cdek` тоже знает все три** (`test-cdek:44` / `:137` / `:435`), то есть
   препятствие не в нём.
4. **Вендоренный IMask генерируется побайтно тем же**: 59248 байт тела, ровно как записано в
   ADR-011 для исходной загрузки с jsDelivr. Изменилась только шапка.
5. **`lint:phone-masks` существовал с s109 и НЕ был подключён в CI** — страж устаревания из ADR-011
   нигде не выполнялся. Оба гейта теперь шаги джобы `test-js`, и лог джобы прочитан обратно.
6. **Заглушек `WP_REST_Request` было ЧЕТЫРЕ, а не две**, и три из них неймспейсные намеренно, так
   что гонки не было. Настоящая причина отсутствия тайп-хинтов: **неймспейсный двойник не может
   удовлетворить глобальный тайп-хинт**.
7. **`git branch --merged` под squash-мержем врёт втрое:** говорит 36, доказанно влиты 107 из 109.

# Ловушки

1. **Риг я мутировал тремя способами и все три вернул** — две константы ПВЗ (`true`/`viewport`),
   `woodev_customer_location` (побайтно то же значение) и город/регион покупателя WC. Проверено
   открытием модалки: карта, тайлы, кластеры московских точек. **Если что-то в ПВЗ поведёт себя
   странно — сперва сверить эти три места.**
2. **Тело PR закрывает карточки ЧЕРЕЗ ОТРИЦАНИЕ, и предупреждения в брифе НЕ ХВАТАЕТ.** Сработало
   второй раз подряд (s111 → s112), причём бриф правило нёс дословно. Писать не запрет, а шаблон:
   `Refs #N — <что осталось>`. И **проверять после каждого мержа**: `gh issue view N --json state`.
3. **Serena игнорирует не только `tests/`**: `tests/** docs/** .github/** .ai/** .serena/** .claude/**`.
   Правило с исключением теперь в `AGENT-RULES.md` и `CLAUDE.md` — раньше оно было только в готче,
   и поэтому бриф семь сессий подряд требовал невозможного.
4. **Ворктри стартуют грязными с СЕМЬЮ CRLF-файлами, не четырьмя** (прошлый хендофф врал). Orca
   отказывается удалять ворктри, пока они грязные, а `git checkout --` их не чистит —
   нужен `orca worktree rm --force`.
5. **Гейты размера сработают:** `AGENTS.md` у потолка, `CURRENT-STATE.md` в s112 его пробил и был
   ужат. Любая вставка обязана что-то вытеснить, и вытеснять надо ИСТОРИЮ, а не живой факт.
