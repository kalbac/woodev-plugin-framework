# Что доказано замером

1. **Правило «required» реализовано ДВАЖДЫ** — сервер `validate()` и браузерный `refreshGate()`.
   Починка одной половины оставляет вторую: #708 закрыл сервер, а кнопка осталась мёртвой до #721.
   Готча `the-checkout-required-rule-has-two-halves-and-fixing-one-leaves-the-other`.
2. **«Нажал принудительно — прошло чисто» локализует дефект в одну фразу:** сервер принял, значит
   отказывал клиент, и сервер копать незачем.
3. **WooCommerce НИКОГДА не блокирует «Place order» сама** — семь пустых обязательных полей, кнопка
   активна. Блокировка существует только потому, что её ввели мы (#274).
4. **Все 13 точек ПВЗ фикстуры — в Москве**, фильтр по bounding box. При другой дефолтной локации
   ПВЗ непроверяем в принципе. Это и есть содержание #270.
5. **`plugins-reference/` не отвечает на «сколько потребителей у v2-API»** — там фреймворк
   1.3.3/1.4.0. Готча `plugins-reference-predates-every-v2-api`.
6. **У DaData схлопываются ключи региона и НП** в РФ (Москва, Питер, Севастополь, Байконур) и у
   большинства крупных городов BY/KZ/UZ. Никогда не проверять `ancestors()` напрямую — спрашивать
   `is_within()`. Готча `dadata-collapses-region-and-settlement-into-one-key`.

# Ловушки

1. **Тело PR закрывает карточки в обход хука `commit-msg`**: GitHub видит ключевое слово рядом с
   номером и ИГНОРИРУЕТ отрицание вокруг него. Готча
   `a-pr-body-closes-cards-that-the-commit-msg-hook-would-have-refused`.
2. **`gh project item-list` молча обрезает по `--limit`** — на доске 338 элементов. Там же.
3. **RAM — настоящий потолок агентов, а не квота.** Воркер умер на `agent_prompt_stalled` при
   1,6 ГБ свободных из 15,3, и после освобождения воркера память НЕ вернулась выше ~2 ГБ: её держат
   языковые серверы и контейнеры. Мерить ПЕРЕД волной.
4. **`worker-read` и `terminal read` отдают ПУСТЫЕ буферы** при живых воркерах. Признаки жизни:
   ЗАГОЛОВОК терминала (воркер ставит его сам) и `git status --short` в ворктри.
5. **Serena `replace_content` переворачивает EOL** — проверять `git diff --cached --stat`.
   **Bash-heredoc рвётся** на длинном тексте с кириллицей: доки писать инструментом записи.
6. **Ворктри стартуют грязными**: четыре файла с одними CRLF. Никогда `git add -A` там.
7. **Гейты размера сработают:** `AGENTS.md`, `CURRENT-STATE.md` и этот файл у потолка. Любая
   вставка обязана что-то вытеснить, и вытеснять надо ИСТОРИЮ, а не живой факт.
