A PHP framework for building WooCommerce plugins. It gives a plugin a loader that lets several plugins
share one framework copy, typed settings with a React admin page and setup wizard, an API client, and a
complete shipping toolkit — rates, box packing, pickup points with maps, checkout fields, an orders
screen, documents and tracking — so the plugin itself contains only its own logic.

**Documentation: <https://kalbac.github.io/woodev-plugin-framework/>**

## Quick start

1. Download `woodev-plugin-framework-<version>.zip` from the
   [latest release](https://github.com/kalbac/woodev-plugin-framework/releases/latest). It contains only the
   `woodev/` folder; unpack it into your plugin's root.
2. Follow [Your first plugin](https://kalbac.github.io/woodev-plugin-framework/getting-started/your-first-plugin/).

The documentation's
[Requirements & bundling](https://kalbac.github.io/woodev-plugin-framework/getting-started/requirements-and-bundling/)
page has a ready-made command for the current version.
